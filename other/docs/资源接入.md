# 资源接入

界面不认"哪个作品"，只认**文件名与清单**。本文说明资源怎么放、怎么换。

> 本项目不提供任何素材，也不提供获取素材的手段。
> 你放什么资源、从哪来、是否有权使用，完全由你自己负责。

## 一、目录约定

```
program/res/assets/
├── ui/            界面图集与按钮
│   ├── sys_*.png      系统界面部件
│   ├── save/          存档界面专用件
│   └── opt/           设置界面专用件
├── snd/           音效 + catalog.json
├── bgm/           背景音乐
├── char/          立绘
├── bg_*.png       场景背景
└── ui_logo.png    标题 logo
```

缺失的文件不会报错：界面会用占位块或系统字体顶上，逻辑照常运行。这对"先跑起来再补素材"很有用。

## 二、命名约定

文件名就是接口。改名等于换素材，不需要动代码。

| 前缀 / 模式 | 用途 | 备注 |
|---|---|---|
| `sys_NNNNN.png` | 系统界面部件 | 编号固定，见 `index.html` 引用 |
| `save/*.png` | 存档界面部件 | 槽位、数字、时间戳、按钮、提示框 |
| `snd/se_NN.mp3` | 音效 | 由 `snd/catalog.json` 列出 |
| `bgm_*.mp3` | 背景音乐 | 同上 |
| `char/<outfit>_<emotion>.png` | 立绘 | 服装号 + 情绪 |
| `bg_<scene>.png` | 背景 | 场景名 |

## 三、清单文件 `snd/catalog.json`

音效与 BGM 不靠扫描目录，而是读清单：

```json
{
  "se": [
    { "id": 0, "file": "se_00.mp3" },
    { "id": 1, "file": "se_01.mp3" }
  ],
  "bgm": [
    { "id": 0, "file": "bgm_menu.mp3", "name": "主菜单" }
  ]
}
```

界面里的「悬停 / 点击 / 取消」音效对应 `id`，存在用户配置里（默认 `0 / 1 / 2`）。
设置界面提供下拉与「试听」，可以边听边换。

## 四、文字与字体

界面文字由后端渲染成图片，渲染顺序：

1. **字模图集**（若 `assets/` 下的字形图集与映射表存在）→ 与原图完全同源的字形
2. **系统字体**（`gdi_text.py`）→ 兜底，清晰但风格不同

字形图集的格式与映射表结构见 `atlas.js` 与 `sub_render.py`。

## 五、立绘与背景

- 立绘按 `char/<服装号>_<情绪>.png` 命名，情绪名与对话里的 `<emotion>` 标签对应
- 背景按 `bg_<场景名>.png` 命名，场景名由剧本/对话逻辑给出
- 切换时前端做淡入淡出，不需要额外配置

## 六、音效文件格式

- 建议 MP3 或 OGG，采样率 44.1kHz
- UI 音效建议 **短于 0.4 秒**：点击音 0.1~0.3 秒最自然
- 文件体积不影响加载（按需请求），但总数量建议控制在 100 个以内

## 七、接入步骤

1. 把素材按上面的约定放进 `program/res/assets/`
2. 若素材编号与默认不同，改 `index.html` / CSS 里的引用
3. 音效清单改 `snd/catalog.json`
4. 启动程序，缺什么补什么（控制台会提示具体缺哪个文件）

## 八、常见问题

**Q：能不能不放素材就跑？**
能。会自动用占位块与系统字体，所有逻辑可跑，只是不好看。

**Q：能不能换成完全不同的风格？**
能。界面是 CSS + 图片，改切图与配色即可；坐标在 800×450 坐标系里重新量。

**Q：能不能接别的 TTS？**
能。只要提供 `GET /api/tts?text=…` 返回 wav，或者改 `tts_client.py` 指向你的服务。
