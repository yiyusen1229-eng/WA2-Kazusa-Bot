## 一、这轮做完的

### 1. 背景图入库（119 张，13.4MB）

- 新增 `tools/import_cg.py`：源图（tga/png/jpg…）→ 统一 1280 宽 **webp q=90**，平均 115KB/张
- 为什么是 webp：同样画质 png 平均 1MB，119 张就是 120MB；WebView2 是 Chromium，webp 原生支持，
  服务端 `mimetypes` 也给 `image/webp`（Python 3.13 实测），不用改静态文件逻辑
- 文件名**原样保留**（中文全角括号也不动），HTTP 路径由浏览器自动百分号编码，实测能加载
- 生成 `assets/cg/index.json`：`id / file / place / kind / time / weather / state`
- `res/assets/` 本来就不进仓库，这 13.4MB 只在本地运行时目录

### 2. 匹配逻辑：新文件 `src/scene_cg.py`

两步走，先定地点再定变体：

- 地点：精确 1.0 → 包含 0.72~0.90 → bigram Dice ×0.62；**低于 0.55 就不换图**（宁可不换，不能乱挑）
- 变体：时间对上 +0.45 / 对不上 −0.55；天气 +0.35 / 没提却下雪 −0.18；细节 +0.30；多出来的细节每个 −0.12
- **时段连续**：没说时间就用当前背景的时段（`/api/chat` 请求体新增 `bg` 字段）
- 天空图（`夜晚天空`、`蓝天白云`…）单独归 `kind=sky`，只有明确说天/云/霞才参选
- 别名表：`咖啡馆→咖啡厅`、`学校→学校大门口`、`家里→和纱家别墅`…，外加旧枚举
  `classroom / cafe / music / street`（旧存档、旧对话都还认）
- 词表（时间/天气/细节）**从 index.json 长出来**，以后加新标签不用改代码

### 3. 提示词：地点表来自素材目录

原来 system 里写死 8 个英文枚举，模型只能在这 8 个里选。现在 `scene_cg.prompt_hint()`
把 47 个地点名拼进去（约 300 字），并说明可以写成「地点（黄昏）」。
素材没导入时自动退回旧的英文枚举，功能不会整个坏掉。

### 4. 修了一个一直没生效的 bug

`_chat()` 里 `split_scene()` 拿了 `scene_now` / `outfit_now`，但**从来没写进返回的 JSON**，
前端读的 `d.scene` 永远是 undefined —— 也就是说之前 `<scene>` 标签解析完就丢了。
这轮把 `scene` / `outfit` / `bg` 一起返回。

### 5. 前端（`ui/game.js`）

- `CG_URL`：启动时 fetch `assets/cg/index.json`
- `bgSrc()`：CG id → 旧的四张 `bg_*.png` → 兜底教室（旧存档的 `classroom` 照样能读）
- `setBg()` 只改了一行（取图方式），淡出淡入逻辑没动
- `send()` 请求体带 `bg: currentBg`；回复里读 `d.bg`，仍在「语音就绪、文字出现」那一刻切图
- `__bgThumb()` 走 `bgSrc()`，存档槽缩略图跟着换
- 新增 `window.__scenePreview(name)` 给探针/调试用

## 二、验证记录

**单测** `tools/test_scene_cg.py`（9 组、30 项，全过）：

- 标签拆解：`和纱家别墅（客厅）（黑夜）` → 地点/细节/时间各自到位
- 精确匹配：黄昏咖啡厅、黄昏图书馆、圣诞大路口、温泉客房
- 只说地点不挑特例：`咖啡厅` → 白天那张，不会挑到下雪/圣诞
- 时段连续：`咖啡厅（晚上）` → `街上` = `街上（晚上）（人行道）`
- 说不清就不换：`完全不存在的地方` 返回空
- 天空图不外溢；旧枚举 `classroom/cafe/music` 都能落位

**接口**（`--serve-only --port 8792`）：

```
/api/scene/match?q=大学图书馆（黄昏）&prev=咖啡厅（晚上）
→ {"id":"大学图书馆（黄昏）","place_score":1.0,"score":0.45,"why":"time=黄昏"}
/api/scene/list → items=119 places=47 sky=夜晚天空、日暮云彩、蓝天白云、阴天天空、黄昏霞光
/game/assets/cg/大学图书馆（黄昏）.webp → 200 image/webp 93774 bytes
```

**真机（WebView2，`tools/ui_probe.py`）**：

1. 直接 `__scenePreview("大学图书馆（黄昏）")` → `bgStyle` 是百分号编码后的 webp 地址，
   `__curBg.naturalWidth = 1280`（不是 404 退回教室），截图确认画面正确
2. **整条链路**：stub 掉 `/api/chat` 让它返回 `bg: "咖啡厅（黄昏）"` → 点发送 →
   背景从 `教室（白天）（空无一人）` 切到 `咖啡厅（黄昏）`，台词正常出字，截图见附档

**119 张全部用 PIL 解码过**：无坏图、全部 1280×720、18KB~281KB。

## 三、踩到的坑

1. `main.py` 里 `Copy-Item -LiteralPath "src\*.py"` 不会展开通配符，同步了个寂寞，
   起来之后 `/api/scene/*` 全 404 —— 改用 `Get-ChildItem | Copy-Item -LiteralPath`。
   （`run_dev.py` 用的是 Python 的 `shutil.copy2`，不受影响，所以正常双击启动没事。）
2. **文件名里的全角括号** `（）` 在 URL 里必须编码。浏览器 `url()` 会自动编码，实测 OK；
   但如果以后手动拼 `fetch()`，记得 `encodeURI`。
3. 素材里 `温泉旅馆（温泉浴场）` 实际画的是客房，所以「温泉旅馆」会挑到它。
   不是匹配的问题，是原图名和内容不符；要客房得说「温泉旅馆（房间内）」。
4. `#bgLayer` 有 260ms 淡出，切图后立刻截图会拍到半透明——探针里 `--wait 2000` 才稳。
