## 2. 「常驻记忆书」为什么是空的

翻了三份文档，结论是：**这个位置确实是给角色配置的常驻记忆书用的，但项目里从来没有默认内容文件。**

| 出处 | 原文 |
|---|---|
| `需求原文_两个待完成版块.md` L11 / L27 | 「这个记忆书不同于刚刚我们提到的记忆书，它是**作为每次打开程序就默认连接到模型的记忆书**」 |
| `未完成功能.md` | 「内容：**用户手写的**角色背景 / 关系 / 既定事实」「什么时候生成：**用户编辑，不自动生成**」 |
| `开发日志2026-11-02_13-40-00.md` L242 | `char/memory/`（常驻记忆书）｜**空的**（还没有导入过） |
| `新对话交接说明.md` L441 | 「特别模式的「记忆书」是**常驻记忆书**（角色固定设定，用户导入，`char/memory/`，**现在是空的**）」 |

所以 `characters/和纱/memory/` 空着不是路径没改、也不是我把两种记忆书搞混了：

- 这个目录 = **常驻记忆书**（每轮作为「你记得的旧事」注入，和 `prompt`、`worldbook` 一样是角色设定）
- 自动生成的那份 = **对话记忆书**（「你记得的事」），在存档的 `memory` 字段和 `cache/memory_runtime.json`

区别只是：提示词 / 世界书有现成的默认内容可以复制进角色文件夹，**常驻记忆书从第一版起就是空槽**，
没有可搬的文件。

要补的话有两种做法（需要你定）：

- **A. 你给要点**：我写成 `characters/<角色>/memory/记忆书.txt`，并加进「新角色模板」的铺底逻辑；
- **B. 我出草稿**：从现有 `worldbook.json`（9 条）和 `persona/stage1~4` 里整理出一版「既定事实 / 关系」，
  你再改。（注意它每轮都注入，`未完成功能.md` 里提过要算进 token 预算。）
