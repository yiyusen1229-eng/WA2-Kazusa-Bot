# 开发日志 2026-11-02 18:40

> 主题：右键与滚轮的「只在当前界面响应」——右键退出浮层不再连带隐藏对话框；对话界面滚轮上滑打开回想。

## 1. 右键：浮层开着时只关当前这一层

**原来的问题**：右键监听挂在 `document` 上，只认 OPTION 2 的「右键功能」（用户设的是隐藏窗口）。
所以设置 / 存读档界面开着时右键，走的是 `body.uiHidden` 那条路——整屏（含对话框）一起被藏掉，
看起来像「两个界面同时响应了同一个右键」。

**改法**（不动用户的 prefs，只改响应顺序）：

- `screens.js` 新增 `closeScreen(el)`：关一个浮层 + 收拾 `dlgConfirm` / `dlgToast`；
  设置页额外走 `__closeOptions` 把 `__optOpen` 标志一起复位。
  EXIT 键改为调它（原来是同一段逻辑写在 `wireExit` 里）。
- `screens.js` 新增 `__closeTopScreen()`：先收存读档的确认框；没有再关「开着的那个 `.uiScreen`」；
  都没有返回 `false`。
- `game.js` 的 `contextmenu`：`uiHidden` 恢复判断之后、读 `rightClick` 之前，先调 `__closeTopScreen()`，
  关掉了就直接返回；`backlogOpen`（回想面板不是 `.uiScreen`）同理先 `toggleBacklog(false)`。
- 对话界面（没有任何浮层）的右键行为完全不变：还是按 prefs 的 hide / options / save 走。

## 2. 滚轮上滑：对话界面打开回想

`game.js` 新增一个 `document` 级 `wheel` 监听（`passive:false`），条件是：

- `deltaY < 0`（只认上滑）
- `#gameScreen` 有 `.active`（标题画面不响应）
- 没有 `uiHidden`、没有 `.uiScreen.show`（设置 / 存读档 / 回想 / 特别模式都不抢）
- 回想没开着（开着时滚轮交给面板自己翻）
- 不在 `#dbgPanel` 里（调试日志自己滚）

满足就 `toggleBacklog(true)` 并 `preventDefault()`。
