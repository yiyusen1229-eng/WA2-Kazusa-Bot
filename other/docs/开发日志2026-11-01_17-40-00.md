## 一、「窗口模式和全屏模式一样大」

**现象**：点「窗口模式」和「全屏模式」看起来没区别。

**原因**：这台机器是 4K + 250% 缩放。程序开窗是 `1280×720` **DIP**，
换算成物理像素是 3200×1800，本来就占了屏幕的 83%；全屏是 3840×2160。
两者只差四周各 320px，frameless 窗口下基本看不出来。
如果之前还点过「最大化」，退出全屏后回到最大化尺寸，就更一模一样了。

**修法**：退出全屏时显式回到一个明确的窗口尺寸，而不是"恢复原样"：

```python
WINDOWED_SIZE = (1024, 576)      # DIP，也是程序的 min_size

w.toggle_fullscreen()   # 出全屏
w.restore()             # 解除最大化
w.resize(*WINDOWED_SIZE)
w.move(居中)             # 注意 move() 收 DIP，GetSystemMetrics 给物理像素，要先除 DPI
```

实测（`win_size_probe`）：

| 状态 | 物理像素 |
|---|---|
| 初始 | 3168×1707 |
| 全屏 | 3840×2160 |
| 窗口模式 | **2560×1440，居中 (640,360)** |

现在两者差 1280×720 像素，肉眼一眼能分。嫌大/嫌小改 `WINDOWED_SIZE` 这一个常数就行。

> 坑：`w.move()` 的参数是 **DIP**，`GetSystemMetrics` 给的是物理像素。
> 先用 `(sw / dpi - 宽) / 2` 换算，否则会移到屏幕右下角外面（第一次就移到了 1600,900）。

## 二、透明度把字也变淡了 —— 只该淡 UI

**现象**：拖「窗口透明度」，正文/名字/按钮上的字跟着一起变淡。

**原因**：上一版是给 `#msgWrap` / `#inputBar` 整块设 `opacity`，
opacity 会作用到整棵子树，字当然一起淡。

**修法**：改成用 CSS 变量 `--ui-alpha`，只作用在**底图那一层**：

| 部件 | UI 层（会被淡） | 字（不动） |
|---|---|---|
| 对话框 | 丝带层 `#msgBox::after`（原先是 `#msgBox` 的背景）+ 填充层 `#msgBox::before` | `#namePlate`、`#msgText` |
| 输入栏 | `#inputFrame`（底框图） | `#input`、占位符图 |
| 发送/动作按钮 | `::before` 里的三态底板 | 按钮里的字模 `<img>` |

关键点：

- `#msgBox` 的背景图不能直接改透明度，只能**挪到伪元素**上（`::after`）；
  原来的 `::before` 有 `opacity:.9 !important`，改成 `calc(.9 * var(--ui-alpha))` 才能乘上去。
- 按钮底板同理挪到 `::before`（`z-index:-1` + 按钮 `isolation:isolate` 保证垫在自己内容下面）。
- 窗口 ON/OFF 还是整块隐藏（连字一起），这是用户明确要的。

实测：`--ui-alpha=0` 时截图里对话框框体完全消失，正文和名字**保持全亮**，
按钮只剩字、底板消失。

## 三、设置重启后复位 —— 改成写配置文件

**原因**：主窗口用 `private_mode=True` 启动（每次全新 WebView2 缓存目录），
`localStorage` 每次清空，所以设置保不住。

**修法**：设置落盘到 **`prefs.json`**（和 `config.json` 同目录，即 exe 旁边 /
开发时的 `program/build_env/`），只有设置界面改动时才写。

后端（`main.py`）：

- `GET /api/prefs` → `{"ok":true,"prefs":{...}}`
- `POST /api/prefs` → 整体覆写；先写 `.tmp` 再 `os.replace` **原子替换**，避免写一半留下坏 JSON
- 文件坏了/不存在都当空对象，绝不让界面起不来

前端（`config.js`）：

- 启动时 `Promise.all([catalog.json, /api/prefs])`，两个都就绪才创建 `window.App` ——
  否则 opt.js 的还原会在拿到设置之前跑，界面显示和实际值对不上
- `setPref` → 写 localStorage（同一会话内快）+ 300ms 防抖 POST 到后端

实测：在 OPTION 1 里改成「高速 + 75%」→ `prefs.json` 里出现 `textSpeed:1, winAlpha:75`；
重新打开页面后 `App.getPrefs()` 读回同样的值，界面高亮和滑块位置也对得上。

> 顺带：`prefs.json` 已加进 `.gitignore`（和 `config.json` 一样属于运行时产物）。
