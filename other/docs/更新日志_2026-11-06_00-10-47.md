## 一、选择分支（新功能）

输入框下面多了一个「选择分支」按钮：点一下，让对话模型按当前上下文给 2~5 个分歧选项，
点其中一条就当玩家发言发出去。数量在标题栏「系统 → 选择分支数量」里调（2/3/4/5）。

界面按原版素材 1:1 还原（这块返工过四轮，读数全部来自像素测量，不是估的）：

| 项 | 值 | 怎么来的 |
|---|---|---|
| 条子尺寸 | **490×45** | `sys_00200` 每帧 784×72 × **0.625**（= 800/1280，整套 UI 素材的固定缩放） |
| 位置 | 左端 x=154.7（水平居中）、第 1 条上沿 y=148 | 雪花模板互相关反推（两朵花心相距 392.5 = 628×0.625） |
| 行距 | **52** | 同上，雪花在 y=148 / y=200 命中 |
| 悬停 | 换 `bar_on.png`（**素材阶段把「常态+高亮」按加法烘成一张**，alpha 与常态逐像素相同） | 原版悬停像素 = 段1 + 段2 逐通道相加 |
| 雪花 / 白牌 | `snow.png` 整张叠（同画布同原点）、`tag.png` 取 `sys_00011` 图集 alpha 盒 18×33 | 原版图 |
| 文字 | 补丁字模（白字 + 2px 黑描边），20px 高、全角步进 17.5px，编号与正文同一张 | 原版字身格 32 × 0.625 |

**开着选项也能存档**：存的那一刻如果选项还开着、而且一条都没选，选项会写进存档的
`meta.choice`；读这个档就把那几条原样摆回来，**不再请求模型**。已经选过的不记录。
开着选项时工具栏会浮到选项层上面（否则点不到「存档」）。

详细过程与踩坑：`更新日志_2026-11-05_23-16-17.md`、`更新日志_2026-11-05_23-48-35.md`。

## 二、一键更新（新）

程序启动时查 GitHub 上的 `version.json`，有新版本就在标题栏弹一条可点通知；
点一下自己更新到最新代码（有 `.git` 走 `git fetch + reset --hard`，zip 安装则下载整份快照，
只覆盖代码与文档，不碰角色、素材、存档）。**漏几版都没关系**——不是打补丁，是取最新整份代码。
有未提交改动或未推提交时拒绝 reset（开发者保护）。

## 三、素材提示节流

「素材已更新」不再狂弹：后端 2 秒扫的是素材签名，而角色目录里的 `sessions/`（自动存档、
缩略图）和 `memory/standing.json` 聊天时一直在变，于是几秒弹一次。
现在 `hotreload.SKIP_DIRS`（sessions/cache/_deleted/logs/…）与 `SKIP_FILES`（standing.json）
不参与签名，前端提示也节流到 15 秒一次；放真素材（portrait/voice）仍然立刻生效。

## 四、这一版修掉的几个「看着不对劲」

| 现象 | 真因 |
|---|---|
| 选项条比原版矮一半 | 把顶部高光那条线当成了条高（量出 22，实际 45） |
| 选中时雪花不亮、发灰 | 雪花层也是**加法**（芯色 149 + 条身底色 ≈ 原版读数 159），普通 alpha 盖上去只能 ≤149 |
| 选项框上有条「分界线」 | 输入栏的青色边框横穿选项条那一行；选择分支打开时把输入栏收起来 |
| 选中时一圈黑边 | 两处：① 我加的 `filter: drop-shadow` 把软边压暗 5~10 级；② `plus-lighter` 实时叠加时 `α出=α源+α底` 夹满，软边整块变不透明、CG 被顶掉（最暗 −110）。现在改成素材阶段烘好、悬停只换图，结构上接不出边 |
