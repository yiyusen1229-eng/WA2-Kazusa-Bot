# 更新日志 2026-11-04_16-27-33

> 本轮只改**打包脚本**，不碰运行时逻辑：产物名带版本号与时间戳，安装包不再夹带存档。

## 一、打包产物命名

旧：`release/和纱_本地测试/` + `.zip`

新：`release/和纱_<版本号>_<YYYY-MM-DD_HH-MM-SS>/` + 同名 `.zip`

版本号读自 `program/src/version.py` 的 `VERSION`，时间戳用打包那一刻的时间。
本次产物：

- `和纱_2026-11-04.2_2026-11-04_16-27-18/`（目录，约 289 MB）
- `和纱_2026-11-04.2_2026-11-04_16-27-18.zip`（约 248 MB）

## 二、修掉一个泄漏：安装包里带了存档

第一次打包时 zip 里出现了 `characters/和纱/sessions/1.json`、`6.json`、`7.json`、`8.json`、`auto.json` ——
这些是**用户自己的聊天存档**，不该随安装包发出去。

修复：

- 复制 `characters/` 时按目录过滤：`sessions` / `cache` / `logs` / `text_cache` / `__pycache__` 全部跳过
- 打 zip 时再加一道兜底：路径里含 `/sessions/` 或文件名是 `config.json` 的一律跳过
- 顺手跳过测试时新建的占位角色「新角色」（只有默认种子内容，21.7 KB）

验证（解包核对）：

| 项 | 结果 |
|---|---|
| zip 条目数 | 1449（原 1464：少 5 个存档 + 10 个占位角色文件） |
| 含 `sessions/` 的条目 | 无 |
| 含 `config.json` 的条目 | 无（密钥不外泄） |
| 含 `cache/`、`logs/` 的条目 | 无 |
| `和纱.exe` | 在 |
| `characters/和纱` 的立绘/语音/人设/世界书/记忆书 | 都在（371 条目） |
