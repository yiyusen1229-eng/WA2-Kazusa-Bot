# 最小可用角色包（示例：雪见）

> 这个包是**原创的演示角色**，和任何原作无关。它的作用是让人一眼看清
> 「一个能导入、能对话的角色包最少需要哪些文件」——2.2 KB，6 个文件。

## 内容

```
雪见/
├── name.txt                显示名
├── prompt/base.txt         角色本体（唯一必需的文件；没有会用自带模板铺一份）
├── prompt/stage1.txt       关系阶段 1 的补充（可选）
├── worldbook/worldbook.json 世界书，2 条：冬木堂 / 北方的冬天
├── memory/记忆书.txt         常驻记忆书（可选）
└── memory/standing.json    关系进度（导出时会被脱敏成空摘要、stage=1）
```

**没有立绘、没有语音** —— 这就是最小包的边界：程序会回落到默认立绘和静音，
对话照常进行。想加就先看 [`../../角色包规范.md`](../../角色包规范.md) 的目录说明。

## 怎么用

1. 程序里「特别模式 → 角色 → 导入角色包」，选 `雪见.zip`
2. 切到雪见，随便聊一句
3. 想验证世界书有没有生效：说「书店」或「下雪」，她会提冬木堂 / 走路很慢

## 怎么重新生成

```powershell
cd program
.\build_env\venv\Scripts\python.exe tools\make_min_pack.py
```

改了 `雪见/` 里的任何文本都可以重跑这条命令，zip 会跟着重建。
