# 开发日志 2026-11-02 13:15

> 主题：**特别模式的配置项改成「下拉面板」** —— 点框不再直接弹选文件，
> 而是箭头转 90°、滑出「导入文件 / 查看文件」两个按钮。

---

## 〇、一句话

以前点一下框就直接弹 Windows 选文件窗口，想「先看看现在有什么、或者自己手动换一个」没有入口；
现在点一下先把选项摆出来：要导入就导入，要自己翻文件夹就打开资源管理器。

---

## 一、交互

```
配置角色立绘        ▶  ← 常态（箭头是底框图里自带的）
─────────────────────────
配置角色立绘        ▼  ← 点一下：箭头顺时针转 90°，面板滑出
  ┌──────────┐ ┌──────────┐
  │ 导入文件  │ │ 查看文件  │
  └──────────┘ └──────────┘
```

- 同一时间只开一个（开新的自动收旧的）；再点一下收起
- 点「导入文件」→ 原来的系统选文件窗口，选完面板自动收起
- 点「查看文件」→ 资源管理器打开这一类资源的目录
- 键盘：框头 `tabindex=0`，Enter / 空格 也能开合（`aria-expanded` 跟着变）

## 二、箭头是抠出来的，不是新画的

底框用的是 `sys_04100` 的四帧图集，**箭头本来就画在第 3 帧上**（x 22..34, y 9..23，
12×14 的白色 ▶）。要让它能转，就得和底框分开：

`tools/make_special_ui.py` 新增 `_make_item_frame()`：

1. 每行用箭头左右两侧的像素做**行内线性拟合**，得到该行的背景色
2. 亮度比背景高 78 以上的像素算箭头（含抗锯齿边），再**膨胀 1 圈**把边缘吃干净
3. 命中区域用拟合出来的背景色补平 → 存成 `item_frame.png`（400×128，四帧，其它三帧原样）
4. 命中的像素按 `(亮度 - 背景亮度) / (255 - 背景亮度)` 存 alpha → `item_arrow.png`（12×14 RGBA）

CSS 里箭头按它在原底框中的**百分比**定位（`left:5.5% top:28.125% width:3% height:43.75%`），
开合时 `transform: rotate(90deg)` + 0.2s 过渡，和文字/底框缩放永远对得上。

> 补洞如果不膨胀，箭头边上会留一圈抗锯齿轮廓（第一次做就踩了，8 倍放大看得见）。

## 三、面板

- `.spPanel` 用 `max-height: 0 → 34px` + `opacity` + `translateY(-3px)` 做滑出
- **上下 padding 只在打开时加**：`box-sizing: border-box` 也夹不住 padding，
  关着时留着 5px 上下 padding 会白占 10px，把下面 4 个框全顶开（第一版就这样，实测行距 25.5→36）
- 面板背景是深色渐变，按钮复用「保存」那套 `btn_3state.png` 三帧图
- 两个按钮由 `special.js` 的 `buildPanel()` 生成（5 个框共用一份结构，不在 index.html 里复制 5 遍）

## 四、「查看文件」

新增 `POST /api/special/open {kind}` → `special_files.open_folder(kind)`：

| kind | 打开的目录 |
|---|---|
| `portrait` | `assets/sprites/`（立绘按衣服分目录，开根目录） |
| `prompt` / `worldbook` / `memory` / `voice` | `char/<kind>/` |

- 目录不存在就先 `makedirs` 再开
- **只认这 5 个 kind**，路径全由常量拼出来，不接受前端传任意路径
- Windows 走 `os.startfile`；macOS / Linux 走 `open` / `xdg-open`（备用，实际只在这台 Win 上验过）

## 六、踩到的坑

1. **`box-sizing: border-box` 夹不住 padding** —— `max-height:0` 时元素还是 `padding+border` 那么高。
   要么把 padding 挪到内层，要么只在打开时加（这次选了后者）。
2. **箭头补洞不膨胀会留轮廓**：抗锯齿像素亮度低于阈值，没被算进 mask。
3. 探针截到的「背景里有个大叶子/黑条」是**特别模式的半透明背景透出了标题画面**（老现象，不是这次改的），
   对比改前的截图确认过位置一样，别当成回归。
