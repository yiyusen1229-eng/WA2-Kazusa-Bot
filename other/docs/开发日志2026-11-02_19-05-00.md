## 1. 对话框文字末尾的翻页图标

**素材**：本机解包的原版 `page_02` 精灵（`other/dev/game_pak/gh/gcn_unpack/page_02.tga`）。
`.ani` 里没有坐标表，是**网格**排布：256×512 的图集，8 列 × 15 行、每格 30px、帧 28×28，
共 120 帧；播放 60fps、2 秒一轮（页面里的「文字行」在流动/明暗变化，看起来就是闪烁）。

**做法**：

- 新增 `tools/bake_page_cursor.py`：把 120 帧横向拼成一条 `3360×28` 的图
  → `res/assets/ui/text/page_cursor.png`（3.6 KB）
- `game450.css`：`#pageCursor` 用 `background-position` + `steps(120)` 播动画（2s 一轮），
  尺寸 28×28、`transform-origin: top left`，由 JS 设缩放；删掉旧的 `#moreHint`（▼）样式
- `index.html`：删掉 `<div id="moreHint">▼</div>`
- `game.js`：`updatePageCursor()` 按文字图的固定格子算位置
  （每字 28×32、每行 20 字，和服务端 `sub_render.py` 同一套常量）：
  `left = col*28*scale`、`top = (line*32+2)*scale`，`scale = 图显示宽 / 图原始宽`。
  触发时机：打字结束 / 点一下立刻显示整句 / 换页；**正在打字、最后一页、兜底打字机模式都不显示**。
  元素挂在 `#msgText` 里（每次重渲染会被清空，`pageCursorEl()` 负责补回来）。

验证（`ui_probe`，真 WebView2）：

- 两页文本 → 第一页打完：`display:block, left:350px, top:41px, scale .6259`（= 第 3 行第 20 字之后）
- 翻到第二页（最后一页）：`display:none`
- `getComputedStyle().backgroundPosition` 依次是 `-504px / -1316px / -2184px`（动画在跑）
- 截图：`other/dev/tmp/rw/h_icon.png`

## 3. 多角色管理

### 目录结构（用户数据目录下，开发时是 `program/build_env/`）

```
characters/                总角色资源文件夹（原来的 char/ 搬进来）
    active.json            当前角色：{"id": "和纱"}
    和纱/
        name.txt           角色名（对话框左上角 / 输入框占位符都跟着它）
        prompt/            提示词（整份替换 persona）
        worldbook/         世界书
        memory/            常驻记忆书
        voice/             参考音频
        portrait/          立绘：<衣服3位>/kaz<衣服3><变化3>.png + index.json
```

- 第一次启动自动迁移：`char/prompt|worldbook|memory|voice` 里的文件搬进当前角色文件夹
  （角色名取老的 `char/name.txt`，没有就用「和纱」），搬空后删掉老目录
- `persona/`、`worldbook/`（程序自带的那一份）**不搬**，仍然是「谁都没导入时的兜底」；
  角色文件夹里有的优先。所以新角色一开始用的是自带人设，导入提示词后就整份替换

### 后端
