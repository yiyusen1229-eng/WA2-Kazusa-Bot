## 几个必知的坑

1. **只起后端**必须带 `WA2_ASSETS_DIR`，否则 `/game/assets/**` 404。
2. 前端改了要 **bump `index.html` 的 `?v=`**，否则 WebView2 可能用旧缓存。
3. 探针 `--js/--check` 收的是**文件路径**，不是 JS 字符串；脚本要包成 IIFE（顶层 `return` 会报错）。
4. `ui_probe` 截图偶尔会缩成 391×66，重跑一次即可。
5. 存档按角色隔离在 `characters/<角色>/sessions/`；`WA2_SESS_DIR` 设了就以它为准。
6. 发布流程：先打 tag → 把上一版补丁合进 master → 再生成新补丁，**旧补丁不删**。
7. `program/logs/run_state.json` 是「本次运行」标记：强杀进程（任务管理器 / 直接 kill）会留下它，
   下次启动会提示「上次没有正常退出」——这是设计行为，不是 bug。
8. 演出过渡的开关是 `prefs.json` 的 `xfade`（`false` = 直接切）和 `xfadeMs`（夹在 200~300）；
   菜单「环境设置 → 演出过渡」改的就是它。
9. TTS 缓存 wav 旁边有 `<hash>.wav.gain.json`（响度 / 增益）；删 wav 时侧车一起删，
   只删侧车会在下次命中时重新量。
10. 调试面板（Ctrl+Shift+D / 标题栏「调试」）打开时每 1.5 秒问 `/api/debug/state`，
    只读、只回数字和标签；关着时不发请求。想看某一轮的分段就发一句再看面板。
11. 改任何「调了会变行为」的数字，先看 `other/docs/参数与指标.md`（47 个参数的区间 / 影响面 /
    风险 / 验收方式）；改完跑 `param_table.py --write` 再 `test_params.py`，表才不会和代码脱节。
12. 提交前跑 `python program\tools\run_smoke.py`：20 份自测 + 静态检查 + 在线冒烟，约 6 秒。
    里面把前端拆分告警基线钉在 91，涨了就是这次改动带进来的。
13. 日志默认留 14 天（`WA2_LOG_KEEP_DAYS`）；`/api/text`、`/api/tts` 的查询串**不写进日志**，
    因为那两串就是对话 / 朗读文本。分享日志用「帮助 → 导出诊断包（默认不含对话）」，别直接发原文件。
14. 性能采样写 `logs/perf-<日期>.csv`（每 20 轮一行，`WA2_PERF=0` 关掉）；
    像素对齐用 `tools/measure_ui.py compare 原图 截图 --asset 宽x高`，差 >1% 就退出码 1。
