## 几个必知的坑

1. **只起后端**必须带 `WA2_ASSETS_DIR`，否则 `/game/assets/**` 404。
2. 前端改了要 **bump `index.html` 的 `?v=`**，否则 WebView2 可能用旧缓存。
3. 探针 `--js/--check` 收的是**文件路径**，不是 JS 字符串。
4. `ui_probe` 截图偶尔会缩成 391×66，重跑一次即可。
5. 存档按角色隔离在 `characters/<角色>/sessions/`；`WA2_SESS_DIR` 设了就以它为准。
6. 发布流程：先打 tag → 把上一版补丁合进 master → 再生成新补丁，**旧补丁不删**。
