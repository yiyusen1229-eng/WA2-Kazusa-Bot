## 一、名字读错：数据文件根本不存在

`tts_client.normalize_ja_names()` 一直在跑（`lang=ja` 时逐句替换），但它只从
`characters/<角色>/pronunciation.json` 读映射表。全仓库搜 `pronunciation.json`：**0 个文件**。

所以那版「纠正角色名读音」只上线了代码。补了一份（13 条）：

```json
{"春希": "はるき", "雪菜": "せつな", "冬馬": "とうま", "冬马": "とうま",
 "和紗": "かずさ", "和纱": "かずさ", "曜子": "ようこ", "武也": "たけや",
 "依緒": "いお", "依绪": "いお", "千晶": "ちあき", "小木曽": "おぎそ", "小木曾": "おぎそ"}
```

验证（真机环境跑 `normalize_ja_names`）：

```
あたしの…あたしの春希…   → あたしの…あたしのはるき…
雪菜には、悪いけど       → せつなには、悪いけど
北原春希、あんたってやつは → 北原はるき、あんたってやつは
```

映射表按 mtime 缓存，**不用重启**，下一句就生效。

**为什么会丢**：角色包导出/导入明确不带 `pronunciation.json`（`char_pack.py` 口径 +
`04_角色与资源.md`），角色文件夹整包重整一次就没了。是否纳入角色包，待用户拍板。

## 二、语气不变：情绪标签不可靠 + 静默兜底

真机 42 次语音的情绪分布：`30 calm / 11 neutral / 1 毒舌`。
参考音频本身没问题——`pick_ref()` 对毒舌/撒娇/哭腔/调侃吐槽/问句 都挑到了各自目录（实测表见已完成记录）。

用真实配置（`deepseek-flash` + 真 system 提示词 + 21 条 fewshot）A/B 探测，同一句重复问：

| 台词 | 模型给的标签（多次） |
|---|---|
| 生气「大っ嫌い！」 | 调侃吐槽 / 毒舌 / 没给 |
| 难过「どうせあたしなんて」 | 毒舌 / 没给 |
| 温柔「ありがと…助かった」 | 没给 / 没给 |
| 提问「それで？」 | calm / 问句 / 没给 |
| 平常「寒いな」 | calm / 毒舌（换词表顺序后） |

两条硬结论：

1. **模型对这个标签不可靠**，而且**改词表顺序只会把偏置挪到另一个词**（把毒舌排第一，平常句就被标成毒舌），
   所以最终**没有换词表顺序**。
2. `split_emotion()` 没标签时静默返回 `calm`，于是「模型偷懒」和「模型真说 calm」在日志里长得一样，
   一直没人发现。

### 改法

| 改动 | 文件 | 说明 |
|---|---|---|
| 新增 `infer_emotion()` | `text_parse.py` | 没标签时按台词形态猜：`？`→问句；`涙/ごめん/ひどい`→哭腔；`ばか/うるさい`→毒舌；`別に/ずるい`→撒娇；`ありがと/好き`→soft；没线索才 calm |
| 新增 `LAST_EMO_SOURCE` | `text_parse.py` | `tag` / `inferred` / `default` / `override`，给日志用 |
| 硬矛盾纠偏 | `text_parse.py` | 明显难过（`涙/ごめん/どうせ/いらない/もういい/さよなら`）却标成 `calm`/`毒舌` → 改哭腔；其它标签一律尊重模型 |
| 一行日志 | `api_chat.py` | `情绪标签推断/缺失：<emo>（模型没写 <emotion>）` |
| 半句提示词 | `api_chat.py` | 「按这句台词的实际语气挑，只有心情真的平复时才用 calm」——词表顺序没动 |
| 自测 | `tools/test_text_parse.py` | 20 → **33 项**（推断 5 种情绪、来源标记、纠偏 3 种、不误纠真毒舌） |

## 四、坑

1. **别再「没标签就 calm」**：那等于把模型的偷懒当成稳定情绪，参考音频和立绘表情会一起瘫掉。
   现在有 `LAST_EMO_SOURCE`，任何调用方都能知道这个情绪是怎么来的。
2. **改提示词词表顺序会带来新偏置**：A/B 里把 `毒舌` 排第一，原本该 calm 的平常句被标成毒舌。
   要动就动「按语气挑」的说明，别动顺序。
3. **PowerShell 的 `-replace` + `Set-Content` 会把 UTF-8 文件改成乱码**（本次把 `run_smoke.py`
   整份写坏，已 `git checkout` 复原）。改这些文件一律用编辑器的精确替换，别用 PowerShell 批量替换。
