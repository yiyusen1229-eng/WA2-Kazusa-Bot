## 二、运行时数据流

```
用户输入（中文）
   │
   ├─→ POST /api/chat ──→ 云端 LLM（deepseek-flash）
   │                        ↓ 返回 <action>…</action>「日文台词」
   │
   ├─→ POST /api/tts ───→ 本地 GPT-SoVITS（:9880）→ wav
   │        （带 speak_ja 时直接念日文；否则先经翻译模型）
   │
   └─→ GET /api/text ───→ 后端用补丁字模渲染成 PNG（界面所有文字都走这里）
```

云端只负责"说什么"，本地负责"怎么翻译、怎么念、怎么画"。

### 舞台坐标系

所有界面按 **800×450** 写死坐标，外层用 CSS `transform: scale()` 适配窗口大小。
2730×1536 的原图换算系数是 `800/2730 = 0.29304`，见 [界面像素测量方法](界面像素测量方法.md)。

## 七、HTTP 接口

后端是单文件 `http.server`，监听随机端口，pywebview 直接用 `http://127.0.0.1:<port>/game/index.html`。

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/api/ping` | — | 存活检查 |
| GET | `/api/text` | `text` `plain` `max_width` `chars_per_line` `color` | 文字 → PNG |
| GET | `/api/tts` | `text` `lang` `emotion` `speak_ja` | 合成语音 wav |
| GET | `/api/voice/ok` | — | 语音是否可用（不预热） |
| POST | `/api/chat` | `{messages, model?, base_url?}` | 对话 |
| GET | `/api/session/list` | — | 存档列表（不含缩略图本体） |
| GET | `/api/session/load` | `slot` | 读档 |
| POST | `/api/session/save` | `{slot, messages, meta}` | 存档 |
| GET | `/api/session/thumb` | `slot` | 缩略图 JPEG |
| GET | `/api/window` | `action`（`close`/`min`/`togglemax`/`dragbegin`/`state`/`resize`/`restore`…） | 无边框窗口控制 |
| GET | `/api/ollama` | — | 本地模型列表 |
| GET/POST | `/api/modelcfg` | — | 模型配置 |
| GET | `/api/model/probe` | `url` | 探测端点是否可用 |
| GET | `/api/usage` | — | 本次运行的 token / 花费累计 |
| GET | `/api/price` | `model` | 当前单价（官网抓取，抓不到用内置表） |
| GET | `/api/log/dump` | — | 导出日志 |

> 参数名统一用自描述命名；旧短名（`t` / `emo` / `sp` / `per_line` / `c` / `act`）仍作为别名接受，方便旧前端。

## 八、关键数据文件

### 存档 `program/build_env/sessions/<slot>.json`

```json
{
  "slot": "3",
  "saved_at": "2026-11-01 04:44:58",
  "messages": [
    { "role": "user", "content": "晚上好" },
    { "role": "assistant",
      "content": "<emotion>calm</emotion>「夜の挨拶には夜の返事よ。」",
      "zh": "夜晚的问候，就该用夜晚的问候回应。" }
  ],
  "meta": { "bg": "classroom", "outfit": "001", "at": 1793501098000, "thumb": "data:image/jpeg;base64,…" }
}
```

- `content`：语言模型原句（含 `<action>` / `<emotion>` 标签，不过滤）
- `zh`：翻译模型输出的中文（界面与存档末句用它）
- `thumb`：存档时截的画面（背景 + 立绘），列表接口只回 `true/false`，本体走 `/api/session/thumb`

### 人设 `persona_core.txt`

每轮都注入的固定前缀（短、稳定），配合 `persona.txt` 的风格规则和 `fewshot.json` 的示例。
