## 一、这次加了什么（按主题）

1. **多角色管理**：`characters/` 总角色资源文件夹，每个角色 `name.txt / prompt / worldbook /
   memory / voice / portrait`；配置角色页可以切换（系统文件夹选择窗）、新建；程序只读当前角色文件夹。
2. **角色完全自包含**：自带 `persona/`、`worldbook/` 降级为模板，第一次启用角色时复制进角色文件夹；
   「查看文件」打开的就是角色文件夹里的那一份。
3. **立绘中文命名**：`portrait/<衣服名>/<表情名>.png`；18 套合并成 14 套（3 组同 label 合并），
   共 278 张；旧编号保留在 `index.json` 的 `code`/`codes`，旧存档照常切。
4. **参考音频进角色文件夹**：`voice/<情绪>/*.wav`；TTS 参考音频根目录改为「角色 voice/ 优先」。
5. **世界书扩容**：9 → 18 条（地点 / 组织 / 时间线），从剧本蒸馏，不编细节。
6. **常驻记忆书**：从世界书提炼 252 字骨架，每轮注入「你记得的旧事」。
7. **剧情检索按角色**：`story.json` 控制开关与索引；新角色默认关（不捞别人的剧情）。
8. **界面**：翻页图标（原版 120 帧）、回想滚到底下滑退出、右键只关当前浮层、滚轮上滑开回想、
   配置角色页的切换/新建按钮。
9. **收敛与清理**：`opt.css` / `save-screen.css` / `special.css` 去重复、去死规则；
   删死代码与重复素材；清掉 `src/` 下的运行时残留。
