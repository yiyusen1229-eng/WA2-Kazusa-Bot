# 场景背景 CG（自动匹配）

> 2026-11-02 加的功能。目标：对话里换地点/换时段时，背景自动跟着换成对应的场景图，
> 不再是四张通用背景轮着用。

## 一句话

模型在回复里输出 `<scene>大学图书馆（黄昏）</scene>` → 后端 `scene_cg.py` 拿
`assets/cg/index.json` 里的**文件名标签**挑一张最贴切的图 → 前端 `setBg()` 切过去。

## 一、素材放哪

```
program/res/assets/cg/
├─ 大学图书馆（黄昏）.webp      ← 名字原样保留，匹配全靠它
├─ 咖啡厅（白天）.webp
├─ 街道…
└─ index.json                  ← 导入工具生成，程序只读它
```

`res/assets/` 整个不进仓库（`.gitignore` 已排除），换机器要重新导一次。

当前这批：**119 张，1280×720，webp q=90，平均 115KB，合计 13.4MB**。
用 webp 不用 png 的原因：同样的画质 png 平均 1MB，119 张就是 120MB；
WebView2 就是 Chromium，webp 原生支持，`mimetypes` 也给 `image/webp`。

## 二、文件名就是标签

格式：`地点（时间）（天气/季节）（地点细节）…`，括号顺序不限。

| 文件名 | 地点 | 时间 | 天气/季节 | 细节 |
|---|---|---|---|---|
| `咖啡厅（白天）.webp` | 咖啡厅 | 白天 | — | — |
| `商业区的大路口（黄昏）（圣诞节）.webp` | 商业区的大路口 | 黄昏 | 圣诞节 | — |
| `和纱家别墅（客厅）（黑夜）.webp` | 和纱家别墅 | 黑夜 | — | 客厅 |
| `教室（白天）（同学都坐在自己的课桌前听讲）（上课中）.webp` | 教室 | 白天 | — | 同学都坐在…、上课中 |

三类词表（`scene_cg.py` 顶部）：

- **时间**：白天 / 黄昏 / 晚上 / 黑夜 / 深夜（另有「早晨→白天」「夜晚→晚上」这类别名）
- **天气季节**：晴天 / 阴天 / 白雪皑皑 / 薄雪 / 冬天 / 圣诞节
- **细节**：剩下所有括号内容。**不用手写词表**——`index.json` 里有什么就是什么，
  新加一张带新标签的图，匹配和提示词自动跟上。

纯天空图（`夜晚天空`、`蓝天白云`、`阴天天空`、`日暮云彩`、`黄昏霞光`）单独归成 `kind=sky`，
只有对话里明确出现「天空 / 云 / 霞 / 夕阳」才参与匹配，否则会把正常场景盖掉。

## 三、导入 / 更新

```powershell
cd program
build_env\venv\Scripts\python.exe tools\import_cg.py --src <场景原图目录>
```

| 参数 | 作用 |
|---|---|
| `--src` | 原图目录（tga / png / jpg / bmp / webp）**必填** |
| `--dst` | 输出目录，默认 `program/res/assets/cg` |
| `--width` | 最大宽度，默认 1280（等比缩放；0 = 不缩放） |
| `--quality` | webp 质量，默认 90 |
| `--force` | 已存在也重转（默认比 mtime，源图没变就跳过） |
| `--prune` | 删掉输出目录里「源图已经不存在」的旧 webp |
| `--dry-run` | 只列清单，不写文件 |

- 加图：把新图丢进源目录，重跑一次即可；同名文件会自动覆盖。
- 删图：重跑时带 `--prune`，否则旧 webp 会留在目录里（`index.json` 里不会有它，不影响匹配）。
- **id 就是文件名去掉扩展名**。改名等于换 id，旧存档里的背景会退回教室，改名前想清楚。

## 四、匹配规则（`src/scene_cg.py`）

分两步，避免「差不多就行」把图挑歪。

**第 1 步：定地点**

1. 精确相等 → 1.0
2. 互相包含（「教室」vs「大学教室内」）→ 0.72 ~ 0.90
3. 其余按 bigram Dice 相似度 × 0.62
4. 不够像（< 0.55）→ **不换图**，宁可保持当前背景

地名里混进来的时间/天气会先剥掉再比（「圣诞节的大路口」→「大路口」）。
另有别名表：`咖啡馆→咖啡厅`、`学校→学校大门口`、`车站→站台`、`家里→和纱家别墅` 等，
以及旧版固定枚举 `classroom / corridor / music / street / cafe / home / night / stage`
（旧存档、旧对话里还会出现）。

**第 2 步：在同一地点的变体里挑**

| 情况 | 加减分 |
|---|---|
| 时间对上 | +0.45 |
| 时间对不上 | −0.55 |
| 天气对上 | +0.35 |
| 天气没提、图是雪天/圣诞 | −0.18 |
| 细节对上一个 | +0.30 |
| 图上多出来的细节（没提） | 每个 −0.12×（按长度折算） |
| 没说时间、但和**当前背景**同时段 | +0.30（时段连续） |

所以：说「咖啡厅（黄昏）」就是黄昏那张；只说「咖啡厅」就挑白天那张；
晚上从咖啡厅出门去街上，街上那三张全是晚上，也会正确选晚上。

几个实际结果（`tools/test_scene_cg.py` 里固定的用例）：

| 说 | 当前背景 | 挑中 |
|---|---|---|
| `咖啡厅（黄昏）` | — | `咖啡厅（黄昏）` |
| `大学图书馆（黄昏）` | — | `大学图书馆（黄昏）` |
| `教室` | — | `教室（白天）（人来人往）` |
| `教室（黄昏）` | — | `教室（黄昏）（空无一人）` |
| `和纱家别墅的客厅` | — | `和纱家别墅（客厅）（白天）` |
| `商业区的大路口（圣诞节）` | — | `商业区的大路口（白天）（圣诞节）` |
| `街上` | `咖啡厅（晚上）` | `街上（晚上）（人行道）` |
| `咖啡厅` | `街上（晚上）（人行道）` | `咖啡厅（晚上）` |
| `夜晚天空` | — | `夜晚天空` |
| `完全不存在的地方` | — | （空：不换图） |

## 五、接口

| 接口 | 作用 |
|---|---|
| `POST /api/chat` | 回复里新增 `scene`（模型原话）、`outfit`、`bg`（匹配到的 CG id，没匹配上是空串） |
| `GET /api/scene/list` | 目录（items / places / sky），调试用；前端直接读 `assets/cg/index.json` |
| `GET /api/scene/match?q=大学图书馆（黄昏）&prev=咖啡厅（白天）` | 试匹配，返回 `hit`（含 `score` / `place_score` / `why`，调阈值时看这个） |

`/api/chat` 的请求体新增可选字段 `bg`（当前背景 id）：后端据此做「时段连续」。
前端的 `send()` 会带上 `bg: currentBg`。

## 六、前端接在哪（`ui/game.js`）

| 位置 | 做的事 |
|---|---|
| `CG_URL` | 启动时 fetch `assets/cg/index.json`，id → `assets/cg/<file>` |
| `bgSrc(name)` | 解析顺序：CG id → 旧的四张 `bg_*.png` → 兜底教室 |
| `setBg()` | 先淡到 0.25 再换图（原逻辑不变），换的是 `bgSrc(name)` |
| `send()` | 读 `d.bg`，在语音就绪、文字出现那一刻切背景（和原来切场景的时机一致） |
| `__bgThumb()` | 存档槽缩略图，同样走 `bgSrc()`；旧存档的 `classroom` 照样能读 |
| `__scenePreview(name)` | 调试/探针用：立刻切到某张图，返回 `{bg, url}` |

> 匹配逻辑**只在后端一份**（`scene_cg.py`），前端不做第二次匹配，避免两套规则打架。

## 七、怎么验

```powershell
# 1. 匹配逻辑（不需要起服务）
cd program
build_env\venv\Scripts\python.exe tools\test_scene_cg.py

# 2. 接口
curl "http://127.0.0.1:8791/api/scene/match?q=%E5%92%96%E5%95%A1%E5%8E%85"

# 3. 真机（WebView2）看画面：先起后端再跑探针
build_env\venv\Scripts\python.exe tools\ui_probe.py ^
    --url http://127.0.0.1:8791/game/index.html ^
    --js setup.js --check check.js --wait 2000 --shot out.png
```

`ui_probe` 的 setup 里可以直接 `window.__scenePreview("大学图书馆（黄昏）")`，
check 里读 `getComputedStyle(bgLayer).backgroundImage` 和 `window.__curBg.naturalWidth`
确认图真的加载了（不是 404 退回教室）。

## 八、已知限制 / 下一步

- **只有模型输出 `<scene>` 才切**。这条指令只加在云端人设里（`if cc:` 分支），
  本地 Ollama 那条链路没有这段提示词，本地模型不会主动输出场景标签。
- **素材里有一张图和文件名对不上**：`温泉旅馆（温泉浴场）` 实际画的是客房。
  所以只说「温泉旅馆」会挑到它；要客房请说「温泉旅馆（房间内）」。
- 天空图只有 5 张，且 `天空` 这种泛称会挑到 `夜晚天空`（排序靠前）。要准确请说全名。
- 立绘服装仍按 `OUTFIT_BY_SCENE`（旧枚举）走，新 CG 场景不会自动换衣服；
  换衣服还是靠模型输出 `<outfit>`。
- 待办：特别模式里加一个「场景预览」页，能翻看这 119 张图并手动指定当前场景。
