# 更新日志 · 2026-11-05 23:48 —— 选择分支：开着选项也能存档，读档原样摆回来

> 需求原话：允许打开选择分支的时候存档；此时存档的话，下次读这个档要重新打开原来出现的分支，
> 而不是向模型请求生成；存档时机必须是「选项开着而且一条都没选」；已经选过的不特殊记录。

## 做法（没有新增接口、没有升 schema）

选项跟着存档的 `meta` 走：`meta` 本来就是自由字典（bg / outfit / thumb / 演出参数），
加一个键**不需要**动 `SCHEMA_VERSION`，老档读进来没有这个键就是普通存档。

```
sessions/1.json
  meta: { bg, outfit, at, thumb, choice: ["放开手", "把脸背过去"] }
```

| 环节 | 位置 | 行为 |
|---|---|---|
| 记 | `wt-session.js` `__saveMeta()` | 调 `WA2.choices.pendingOptions()`；**开着且一条没选**才返回数组，否则 null 不写入 |
| 存 | `savepages.js` `saveTo()` → `POST /api/session/save` | 原样落盘（`sessions.py` 不动） |
| 读 | `wt-session.js` `restoreChoices()` | 有 `meta.choice` 就 `WA2.choices.show(options)` 直接渲染，**不请求 `/api/choice`** |
| 反例 | 同上 | 读的档里没有 `choice` 时，把手上一层还开着的旧选项收掉 |

「一条都没选」的判定就是 `state.open`：点选之后那一层立刻 `state.open = false`（淡出中也是），
所以选过之后再存不会带上选项——不需要额外的标志位。

## 一个必须改的地方：工具栏被选项层挡住了

选项层是全屏的（`pointer-events:auto`），工具栏在 z 26，点不到「存档」。
现在 `body.choiceOpen #toolbar { z-index: 78 }` 把工具栏抬到选项层（z 70）上面；
存档 / 回想起这些浮层是 z 120，本来就盖得住。工具栏在右下（y≈421），
选项条最多排到 y≈401，不会互相挡。

顺带修了两处层级顺序：
- `screens.js` 的 `__closeTopScreen()`：之前把「先收选项」放在最前面，导致**存档界面开着时右键
  会关掉底下的选项**。改成 确认框 → 浮层（z 120）→ 选项层（z 70）。
- `wt-choices.js` 的键盘监听：浮层开着时不再抢 `Esc` 和数字键（否则存档界面开着按 Esc
  关的是底下的选项）。

## 验证（真 WebView2 探针，`WA2_SESS_DIR` 指到 work_scratch 的隔离目录，不碰真实存档）

| 步骤 | 读数 |
|---|---|
| 开选项 | open=true、2 条、`__saveMeta().choice` = ["放开手","把脸背过去"] |
| 开着选项点工具栏「存档」 | 工具栏找得到、`#saveScreen.show`=true、`mode-save`、10 个槽 |
| 点 1 号槽 | 后端文件：`ok`、`meta.choice` 两条、`messages` 2 条 |
| 关掉浮层 | 选项仍开着、2 条、输入栏仍是收起的（opacity 0） |
| `__loadSession(存档)` | **open=true、2 条、选项原样**，`/api/choice` 调用次数**仍是 1**（没请求模型） |
| 选一条之后再取 meta | `choice` = null（已选过不记录） |
| 开着选项读一个没有 choice 的档 | open=false、0 条，调用次数不变 |

自测：`test_choice.py` 从 22 项加到 **29 项**（新增 7 项走 `sessions.py` 的
`meta.choice` 往返：存得进、读得回、不挤掉别的 meta、没有就不凭空长、类型乱写不抛、空数组存得住）。

## 覆盖到的边界

- 老存档（没有 `choice`）照常读，不会长出一个空字段
- `meta.choice` 是空数组 / 不是字符串数组：前端 `show()` 过滤后不足 2 条就当没有
- 读档时如果选项本来开着：`show()` 先 `hide()` 再渲染，不会叠两层
- 存档界面要求「对话至少两条」的既有规则不变（所以刚开局还存不了档）

## 没做的

- 存档槽缩略图里不会画出选项条（`__grabThumb` 只画背景 + 立绘），槽位列表也不显示
  「这个档带分支」的标记。要的话加一个角标就行。
- 只记选项文本，不记「当时是哪一轮的选项」。因为读档会同时恢复 `messages`，
  上下文天然是对得上的。
