## P2：长期

### #17 数据清理入口

**现在**：没有。

**缺**：设置页「清理缓存 / 导出全部数据 / 删除角色数据」；备份可选加密。

**怎么做**：三个入口 + 删除前二次确认；删除角色同步清 `cache/<角色>/`。

**边界**：导出默认脱敏，可选包含对话。

### #18 桌面行为

**现在**：只有窗口自带的 min / max / fullscreen / drag（`api_window.py`）。

**缺**：置顶 / 透明 / 点击穿透、托盘、全局快捷键、多显示器、电源事件。

**怎么做**：`pystray` + `keyboard`；置顶 / 穿透用系统 API；休眠唤醒后重建音频与网络连接。

**边界**：快捷键冲突要提示；托盘退出走正常存档。

### #21 架构图 + 不要动清单（剩余部分）

**现在**：`架构/00_总览.md` + 自动生成的 `映射表.md`（层级 / 导出 / 依赖 / 被谁调用）；`AGENTS.md` 有「不许动的东西」简版。

**缺**：一张数据流图；独立的 `不要动.md`。

**怎么做**：数据流图说明「输入 → 切片 → 提示词 → 模型 → 演出 → 缓存 / 存档」；清单每条写「为什么不能动 / 动了会怎样 / 正确改法」（`globals()`、字体图集边界、像素系数）。

**边界**：图随架构更新，清单随踩坑记录增补。

### #22 角色包规范 / 示例 / 迁移工具（剩余部分）

**现在**：包格式与 `manifest.json` 已有（`char_pack.py`），界面上的导出 / 导入也通了。

**缺**：`角色包规范.md`、`examples/minimal_character/`、`tools/migrate_character.py`。

**怎么做**：写 schema 与校验清单；做一个最小可跑角色（必需文件 + 1 张立绘 + 1 条语音）；迁移工具先备份、不删原文件。

**边界**：规范必须跟 `char_pack.py` 的常量保持一致（改代码要同步改文档）。

### #23 首次启动向导（剩余部分）

**现在**：首次启动若没有 `config.json`，自动生成一份空白模板（`main.py:235`）。

**缺**：向导 UI、内置示例对话、聊天导出 / 分享卡片。

**怎么做**：分步向导（模型服务 / 语音开关 / 角色选择 / 素材路径 / 快捷键），可跳过、可重跑；导出 Markdown / 图片 / 分享卡片，默认脱敏，分享前预览。

**边界**：向导不阻塞已有配置；导出不含密钥和绝对路径。

### #24 模型接入抽象层

**现在**：`api_chat.py` 直接 urllib 调 `/v1/chat/completions`；`tts_client.py` 直接调 GPT-SoVITS；成本显示已有（`wt-cost.js` + `/api/usage` + `pricing.py`）。

**缺**：`LLMAdapter` / `TTSAdapter` / `ASRAdapter`；限流 / 超时 / 余额不足的统一降级；预算提醒。

**怎么做**：统一 `generate / stream / synthesize`；流式解析容错（角色名前缀、Markdown、不完整 JSON），坏块跳过记日志；成本面板加每会话 / 每日用量与预算。

**边界**：适配器可插拔；降级路径要有测试覆盖。
