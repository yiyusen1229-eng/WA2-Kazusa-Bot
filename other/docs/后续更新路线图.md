## P1：体验与可维护性

### #15 日志诊断包（剩余部分）

**现在**：`applog.py` 有 INFO / ERROR / DUMP 级别、按天文件、慢请求告警、心跳、线程栈快照；`/api/log/dump` 只是写一份栈快照。

**缺**：保留 N 天滚动；脱敏；真正的诊断包导出。

**怎么做**：日志按天清理；导出前过滤对话内容、密钥、绝对路径、用户名；诊断包 = 日志 + 脱敏配置 + 素材报告 + 版本信息。

**边界**：默认不含对话原文；可选包含最近 N 轮并明确提示风险。

### #14 像素工具化 + 性能采样（剩余部分）

**现在**：`ui_snap.py`（像素回归）、`ui_probe.py`（界面探针）、`界面像素测量方法.md`（手工流程）。

**缺**：输入原图 + 预览图 → 输出偏移量 / 宽高比的脚本；`logs/perf_<date>.csv`。

**怎么做**：把测量方法里的步骤写成脚本并接进自测；每 N 轮记录内存、缓存体积、本地耗时、音频句柄。

**边界**：采样不影响主循环；日志可关。

## P2：长期

### #1 缓存分层与淘汰（剩余部分）

**现在**：启动全清（文字渲染 / TTS / 记忆运行时）+ TTS key 带角色 id 与音色签名——不串音、不涨盘，代价是每次启动重合成。

**缺**：跨启动保留、`cache/<角色id>/<类型>/` 分层、体积上限与 LRU。

**怎么做**：按角色分层；`cache_index.json` 记路径 / 大小 / 最后访问；超限按 LRU 删；删角色时同步清。

**边界**：共享素材（全局字体图集）不按角色隔离。

**注意**：只有「每次启动重合成」真的变成问题时才值得做。

### #3 常驻记忆书更新

**现在**：`memory/` 是静态文本，每轮注入；长期对话后可能和对话记忆书语义漂移。

**缺**：固定设定 + 关系摘要两段；随阶段切换低频刷新。

**怎么做**：`memory/standing.json {version, fixed, relation_summary, updated_at}`；阶段切换时异步更新，失败保留旧版，不阻塞对话。

**边界**：更新频率设上限（如每次阶段切换最多一次）。

### #19 演出 / 切片规则配置化

**现在**：演出与切片规则写死在 JS / Python 里。

**缺**：每角色的 `performance.json`、`persona_slices.json`。

**怎么做**：启动 / 切角色时加载并校验 schema；缺失用默认模板。

**边界**：配置错误回退默认并提示。

### #20 素材导入向导 + 热重载（剩余部分）

**现在**：`check_assets.py` + 按类型的导入面板（立绘 / 提示词 / 世界书 / 记忆书 / 语音）。

**缺**：`asset_report.json`、分步向导、`watchdog` 热重载。

**怎么做**：导入 / 启动扫描输出报告；向导提示缺哪些表情 / 场景标签无图，可跳过；监听素材目录变化，失效对应缓存并重载。

**边界**：热重载失败回退旧素材并记日志；可关闭。

### #17 数据清理入口

**现在**：没有。

**缺**：设置页「清理缓存 / 导出全部数据 / 删除角色数据」；备份可选加密。

**怎么做**：三个入口 + 删除前二次确认；删除角色同步清 `cache/<角色>/`。

**边界**：导出默认脱敏，可选包含对话。

### #18 桌面行为

**现在**：只有窗口自带的 min / max / fullscreen / drag（`api_window.py`）。

**缺**：置顶 / 透明 / 点击穿透、托盘、全局快捷键、多显示器、电源事件。

**怎么做**：`pystray` + `keyboard`；置顶 / 穿透用系统 API；休眠唤醒后重建音频与网络连接。

**边界**：快捷键冲突要提示；托盘退出走正常存档。

### #21 架构图 + 不要动清单（剩余部分）

**现在**：`架构/00_总览.md` + 自动生成的 `映射表.md`（层级 / 导出 / 依赖 / 被谁调用）；`AGENTS.md` 有「不许动的东西」简版。

**缺**：一张数据流图；独立的 `不要动.md`。

**怎么做**：数据流图说明「输入 → 切片 → 提示词 → 模型 → 演出 → 缓存 / 存档」；清单每条写「为什么不能动 / 动了会怎样 / 正确改法」（`globals()`、字体图集边界、像素系数）。

**边界**：图随架构更新，清单随踩坑记录增补。

### #22 角色包规范 / 示例 / 迁移工具（剩余部分）

**现在**：包格式与 `manifest.json` 已有（`char_pack.py`），界面上的导出 / 导入也通了。

**缺**：`角色包规范.md`、`examples/minimal_character/`、`tools/migrate_character.py`。

**怎么做**：写 schema 与校验清单；做一个最小可跑角色（必需文件 + 1 张立绘 + 1 条语音）；迁移工具先备份、不删原文件。

**边界**：规范必须跟 `char_pack.py` 的常量保持一致（改代码要同步改文档）。

### #23 首次启动向导（剩余部分）

**现在**：首次启动若没有 `config.json`，自动生成一份空白模板（`main.py:235`）。

**缺**：向导 UI、内置示例对话、聊天导出 / 分享卡片。

**怎么做**：分步向导（模型服务 / 语音开关 / 角色选择 / 素材路径 / 快捷键），可跳过、可重跑；导出 Markdown / 图片 / 分享卡片，默认脱敏，分享前预览。

**边界**：向导不阻塞已有配置；导出不含密钥和绝对路径。

### #24 模型接入抽象层

**现在**：`api_chat.py` 直接 urllib 调 `/v1/chat/completions`；`tts_client.py` 直接调 GPT-SoVITS；成本显示已有（`wt-cost.js` + `/api/usage` + `pricing.py`）。

**缺**：`LLMAdapter` / `TTSAdapter` / `ASRAdapter`；限流 / 超时 / 余额不足的统一降级；预算提醒。

**怎么做**：统一 `generate / stream / synthesize`；流式解析容错（角色名前缀、Markdown、不完整 JSON），坏块跳过记日志；成本面板加每会话 / 每日用量与预算。

**边界**：适配器可插拔；降级路径要有测试覆盖。
