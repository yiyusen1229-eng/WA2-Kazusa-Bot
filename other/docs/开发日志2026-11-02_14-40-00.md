**下一轮微调人设，主要看 `persona/persona_core.txt` 和这个文件。**

### 2. 日志换行 bug

`main.log()` 原来写的是 `f.write("[%s] %s\\n" …)` —— 写进文件的是**字面量 `\n`**，
所以 `wa2_app.log` 从头到尾是一行。改成 `\n`，以后日志正常分行。
（旧日志里那些 `\n` 就是它。）

### 3. `build_story_index_v2.py` 修正

- 源：`other/dev/dataset/L2_scene.jsonl`（原来写死 `dataset/`，那个目录不存在）
- 输出：`program/src/story_index.json.gz`（原来写到 `app/story_index.json`，早就没这个目录）
- 写完顺手删掉无压缩副本
- 加了 `--src / --out / --chunk` 参数

重建结果：**5618 个场景 → 4592 块 / 408 万字 / 0.8MB**（和旧索引一致）。

### 4. `check_assets.py` 重写

旧版检查的是 `app/`、`最新版/`、`ui2/assets` 这些已经不存在的路径，还带素材来源提示。
新版按现在的目录检查（res/assets、build_env/assets 字模、persona/、worldbook/、
story_index、config、char、TTS、剧本），措辞中性。

### 5. 其它
