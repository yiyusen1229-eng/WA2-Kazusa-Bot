# 架构说明

本文说明分层、数据流、接口与数据结构。面向「想改代码」和「想接入资源」两种读者。

## 一、分层

```
界面层（WebView2）
    │ HTTP
服务层（Python，单进程 http.server）
    │ 文件系统
资源层（resources/，使用者自备）
```

三层之间只通过 **HTTP 接口** 和 **约定好的目录结构** 交互：

- 界面层不知道资源在哪，只请求 `/api/text`、`/api/tts` 这类接口
- 服务层不知道素材来自哪里，只按文件名读取
- 资源层可以随时替换，不需要改任何代码

## 二、运行时数据流

```
用户输入
   │
   ├─→ POST /api/chat ──→ 对话模型（OpenAI 兼容接口）
   │                        ↓ 返回结构化文本（台词 + 可选动作/情绪标签）
   │
   ├─→ POST /api/tts ───→ TTS 服务 → wav
   │
   └─→ GET  /api/text ──→ 后端渲染 PNG → 前端贴图
```

**为什么文字要走后端渲染成图片？**

因为要让界面文字与图集字体完全同源：字形、描边、字距、抗锯齿都对得上。
代价是文字不可选中、不可复制，也拿不到 DOM 文本——这是刻意的取舍。

## 三、坐标系统

- 舞台固定 **800×450**（16:9），所有界面坐标按这个尺寸写死
- 外层用 `transform: scale()` 等比缩放到窗口大小
- 缩放只影响显示，不影响判定：鼠标坐标换算成舞台坐标后再判断

参考尺寸换算：若你手上有 2730×1536 的设计稿，系数是 `800 / 2730 ≈ 0.29304`。

## 四、后端文件

| 文件 | 作用 |
|---|---|
| `main.py` | HTTP 服务、接口实现、窗口控制 |
| `sub_render.py` | 文字渲染（字模优先），输出 PNG；支持 `chars_per_line` / `color` / `max_width` |
| `gdi_text.py` | 系统字体渲染兜底 |
| `tts_client.py` | TTS 服务客户端：拉起、健康检查、合成 |
| `story_rag.py` | 可选的检索模块（给对话补记忆） |
| `applog.py` | 日志与心跳 |
| `persona*.txt` / `fewshot.json` | 人设与示例对话（纯文本，可随意替换） |

## 六、HTTP 接口

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/api/ping` | — | 存活检查 |
| GET | `/api/text` | `text` `plain` `max_width` `chars_per_line` `color` | 文字 → PNG |
| GET | `/api/tts` | `text` `lang` `emotion` `speak_ja` | 文本 → wav |
| GET | `/api/voice/ok` | — | TTS 是否可用（不预热） |
| POST | `/api/chat` | `{messages, model?, base_url?}` | 对话 |
| GET | `/api/session/list` | — | 存档列表（不含缩略图本体） |
| GET | `/api/session/load` | `slot` | 读档 |
| POST | `/api/session/save` | `{slot, messages, meta}` | 存档 |
| GET | `/api/session/thumb` | `slot` | 缩略图 JPEG |
| GET | `/api/window` | `action` | 窗口控制：`close` `min` `togglemax` `dragbegin` `state` `resize` `restore` |
| GET | `/api/ollama` | — | 本地模型列表 |
| GET/POST | `/api/modelcfg` | — | 模型配置 |
| GET | `/api/model/probe` | `url` | 端点探测 |
| GET | `/api/log/dump` | — | 导出日志 |

> 参数名统一为自描述命名；旧短名（`t` / `emo` / `sp` / `per_line` / `c` / `act`）仍作为别名接受。

## 七、数据结构

### 存档 `sessions/<slot>.json`

```json
{
  "slot": "3",
  "saved_at": "2026-11-01 04:44:58",
  "messages": [
    { "role": "user", "content": "晚上好" },
    { "role": "assistant",
      "content": "<emotion>calm</emotion>「夜の挨拶には夜の返事よ。」",
      "zh": "夜晚的问候，就该用夜晚的问候回应。" }
  ],
  "meta": { "bg": "classroom", "outfit": "001", "at": 1793501098000, "thumb": "data:image/jpeg;base64,…" }
}
```

- `content`：模型原句（可含动作/情绪标签，不解析不丢失）
- `zh`：可选译文，界面与存档末句优先用它
- `thumb`：截图缩略图；列表接口只回 `true/false`，本体走 `/api/session/thumb`

## 八、性能相关的实现细节

| 场景 | 做法 |
|---|---|
| 存档列表 | 只回摘要（`thumb` 为布尔），缩略图单独接口 + `Cache-Control` |
| 存档解析 | 按文件 mtime 缓存，界面反复开关不重复解析 |
| 文字渲染 | 结果按 (文本, 参数) 缓存，上限 400 条 |
| 前端资源 | 所有 `<script>` 带 `?v=` 版本号，避免旧缓存 |

## 九、想改某处，看哪里

| 想改什么 | 改哪里 |
|---|---|
| 界面布局/坐标 | 对应界面的 CSS + `scale.js` |
| 文字效果（描边、间距、染色） | `sub_render.py` |
| 存档槽显示内容 | `savepages.js` 的 `fillContent()` |
| 回想面板 | `game450.css` 的 `.hline` 系列 + `game.js` 的 `addHistory()` |
| 人设与语气 | `persona*.txt`、`fewshot.json` |
| 语音参数 | `tts_client.py` |
| 窗口行为 | `main.py` 的窗口 API + `menubar.js` |
