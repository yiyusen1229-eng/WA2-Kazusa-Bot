## 1. 立绘：从「编号」改成「衣服名 + 表情名」

**映射表只有一份**（`special_files.VARIANT_EMOTION`，13 条变体号 → 7 种表情）。

| 变体号 | 表情 | 中文文件名 |
|---|---|---|
| 101 | serious | 认真 |
| 104 / 110 / 134 | cold | 冷淡 |
| 109 / 307 / 323 | smile | 微笑 |
| 115 / 218 | surprise | 惊讶 |
| 125 / 131 / 224 | sad | 难过 |
| 140 | shy | 害羞 |
| 205 / 212 | angry | 生气 |

改法（`tools/rename_sprites.py`，可 `--dry-run`）：

- **目录** = index.json 里每套衣服的 `label`（`001` → `高中·春秋JK制服`）
  - 有 3 组 label 重名（`coda·第一套常服（无外套）` 分别对应 013/030/041 等），
    重名的补原编号后缀：`coda·第一套常服（无外套）_030`
- **文件** = 表情中文名；同一套衣服里同表情有多张就加序号（`生气.png` / `生气2.png`）
- **没有表情映射的 128 张** → `其他.png` / `其他2.png`……（原变体号仍记在 index.json 的 `variants` 里，没丢）
- index.json 结构变成：
  `outfits[<中文衣服名>] = {code, label, default, emotions{英文情绪: 中文文件}, variants[{variant, file, emotion}]}`
  —— `code` 保留，是为了兼容旧存档里的 `meta.outfit` 和模型偶尔吐的旧编号

**结果**：18 套衣服 / 278 张，全部落在
`build_env/characters/和纱/portrait/<衣服名>/<表情名>.png`（原 `res/assets/sprites` 已搬空）。

## 4. 记忆书为什么一直显示空的

不是没搬 —— `char/memory/` 从一开始就是空的（迁移前的 `build_env/char` 里只有空目录 + name.txt）。
「配置角色记忆书」是**用户自己导入的常驻设定**（`characters/<角色>/memory/*.txt`），
程序里没有现成的默认记忆书；对话产生的自动记忆书在存档和 `cache/memory_runtime.json` 里，不是这里。
