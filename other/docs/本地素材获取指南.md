## 一、先跑一次自检

```bash
python tools/check_assets.py
```

输出会列出三项：

```
[已就绪] 19 项
[缺少 · 必需] n 项 —— 不补齐程序起不来
[缺少 · 可选] n 项 —— 缺了仍能跑，但对应功能不可用
```

每一项都带「获取方式」。修完再跑一次，直到必需项清零。

机器可读版本：

```bash
python tools/check_assets.py --json
```

## 三、A 类：能从网上下载的

### 3.1 基座模型（只有想跑本地对话才需要）

```bash
python tools/setup_assets.py --model 14b     # 约 29 GB
python tools/setup_assets.py --model 7b      # 约 15 GB，更省地方
```

# （本项目不做本地训练，无需下载基座模型）

如果脚本失败，手动下：

```
https://modelscope.cn/models/Qwen/Qwen2.5-14B-Instruct
```

或者用 HuggingFace 镜像：

```bash
export HF_ENDPOINT=https://hf-mirror.com
# （本项目不做本地训练，无需下载基座模型）
```

> **注意**：不下载这个也能用程序——对话走云端，本地模型只是离线备选。

### 3.2 GPT-SoVITS（语音合成）

```bash
python tools/setup_assets.py --tts
```

克隆下来之后还差两样，脚本不会自动弄：

1. **独立 python 运行时** —— GPT-SoVITS 官方发布的 `runtime/` 包，解压到 `tts/GPT-SoVITS/runtime/`
2. **Touma_Kazusa 权重** —— 来自 B 站分享（链接见 [参考与致谢](参考与致谢.md)），放到：
   ```
   tts/GPT-SoVITS/GPT_weights_v4/Touma_Kazusa-e15.ckpt
   tts/GPT-SoVITS/SoVITS_weights_v4/Touma_Kazusa_e8_s33072_l32.pth
   ```

### 3.3 翻译模型

```
tts/models/Hy-MT2-1.8B-Q4_K_M.gguf
```

自行下载 Hy-MT2-1.8B 的 GGUF 量化版。没有它只是没有中文对照，程序仍能跑。

## 四、B 类：必须自己解包游戏的

**这一步无法自动化**，因为素材版权归 Leaf / Aquaplus，仓库不能分发。你需要：

1. 购买《WHITE ALBUM 2》（EXTENDED EDITION 或 Special Contents）
2. 安装汉化补丁（[xhyf2666/WhiteAlbum2SpecialCHS](https://github.com/xhyf2666/WhiteAlbum2SpecialCHS)）
3. 自己解包

### 4.1 需要解出什么

| 素材 | 目标位置 | 说明 |
|---|---|---|
| 立绘 | `ui2/assets/sprites/` | 278 张 PNG，按服装分目录，另需 `index.json` |
| UI 图集 | `ui2/assets/ui/` | `sys_*.tga` 切图（对话框、按钮、箭头…） |
| 主菜单按钮 | `ui2/assets/menu/` | 五项的两态图 |
| 工具栏 | `ui2/assets/tb/`、`ui2/assets/tb2/` | 两套按钮 |
| 标题画面 | `ui2/assets/title.png` | |
| 标志 | `ui2/assets/ui_logo.png` | |
| 背景 | `ui2/assets/bg_*.png` | 教室 / 走廊 / 音乐室 / 街道 |
| BGM | `ui2/assets/bgm_*.ogg` | |
| 音效 | `ui2/assets/snd/` | |
| 剧本 | `app/story_index.json` 的原料 | 见 C 类 |

### 4.2 命名规则

代码按固定规则拼路径，所以文件名必须对上：

```
立绘   ui2/assets/sprites/<outfit>/kaz<outfit><variant>.png
       <outfit>   如 uniform、casual、coat
       <variant>  表情编号，如 ""、"_angry"、"_smile"
索引   ui2/assets/sprites/index.json
       {"outfit001": {"emotions": {"angry": 212, "sad": 125, ...}}}
背景   ui2/assets/bg_music.png / bg_corridor.png / bg_classroom.png / bg_street.png
BGM    ui2/assets/bgm_calm.ogg / bgm_sad.ogg / bgm_tense.ogg / bgm_warm.ogg
```

完整的路径来源看 [`docs/架构与文件说明.md`](架构与文件说明.md) 第六章。

### 4.3 解包工具

**本仓库不提供游戏解包器**。

原因：解包器本身不侵权，但配套的密钥/偏移/格式说明属于规避技术措施，不适合放进公开仓库。之前的解包工作是用一次性脚本完成的，这些脚本已经归档，没有入库。

你需要自己找对应版本的解包工具，或者在社区里问。

### 4.4 汉化补丁里的字模

字形图集来自汉化补丁，不是游戏本体：

```
app/assets/subfont.tga            891 个字形，32×32 一格
app/assets/subfont_charset.json   字 → 格子序号
app/assets/字体映射表.json         全角/半角与异体字
```

补丁仓库在 [xhyf2666/WhiteAlbum2SpecialCHS](https://github.com/xhyf2666/WhiteAlbum2SpecialCHS)，
里面 `patch/gcn.pak` 解包后能找到这些文件。

## 六、最小可运行集

```
ui2/assets/sprites/        立绘（至少一套服装几张）
```

自检脚本会自动区分「必需」和「可选」。

## 七、只想改代码、不想弄素材怎么办

三条路，按成本排：

### 7.1 只读代码

不需要素材。先看这两处：

```
app/main.py 的 _chat()      对话主流程
```

### 7.2 用占位素材跑通流程

```bash
python tools/make_placeholder_assets.py
```

脚本会：

1. 扫描 `ui2/` 下所有 js / css / html，找出代码里引用到的 `assets/...` 路径（当前是 83 个）
2. 对每个**缺失**的文件生成一张纯色 PNG，尺寸按代码里出现过的规格推断
3. 按 `game.js` 里的服装编号生成 10 套 × 7 种情绪的立绘占位（768×900）
4. 生成空的字形映射（`subfont_charset.json` = `{}`），让文字自动走 GDI 回退
5. 生成空的 `app/story_index.json`（往事检索不可用）
6. 从 `config.example.json` 复制出 `最新版/config.json`

产出量（实测）：

```
assets/font/     1 个
assets/menu/    10 个
assets/sprites/ 71 个（10 套 × 7 情绪 + index.json）
assets/tb2/     18 个
assets/ui/      36 个
合计           154 个文件
```

参数：

```bash
python tools/make_placeholder_assets.py --dry-run   # 只看会生成什么
python tools/make_placeholder_assets.py --force     # 覆盖已有文件
python tools/make_placeholder_assets.py --root .    # 指定项目根目录
```

**效果**：程序能起来、能对话、能翻译、能存档，但界面是纯色方块拼的，立绘是灰块，文字是微软雅黑而不是补丁字形。

**注意**：占位图生成后，`check_assets.py` 会认为素材齐了（它只检查文件是否存在）。想知道哪些是占位、哪些是真的，看文件大小——占位 PNG 通常几百字节。

### 7.3 只调后端

后端可以完全脱离界面运行：

```bash
cd app
python main.py --serve-only
```

输出：

```
============================================================
  后端模式（不开窗口）
  http://127.0.0.1:8771

  自检      GET  http://127.0.0.1:8771/api/ping
  对话      POST http://127.0.0.1:8771/api/chat
  文字渲染  GET  http://127.0.0.1:8771/api/text?text=测试
  语音      GET  http://127.0.0.1:8771/api/tts?text=テスト

  Ctrl+C 退出
============================================================
```

这个模式**不需要任何图片素材**，只要 `最新版/config.json` 里有 API key 就能调通对话。

用 curl 试：

```bash
curl -s http://127.0.0.1:8771/api/ping

curl -X POST http://127.0.0.1:8771/api/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"今天放学挺早的"}]}'
```

返回（实测）：

```json
{
  "reply": "「……何の話だ」",
  "reply_zh": "……什么话题啊",
  "action": "",
  "action_zh": "",
  "thinking": "",
  "model": "deepseek-flash",
  "ms": 1832
}
```

指定端口：

```bash
python main.py --serve-only --port 9000
```

**适合谁**：只改后端逻辑（对话流程、标签解析、翻译调度）、或者想写自动化测试的人。前端一行都不用碰。

## 八、常见问题

**Q：我没有游戏，能不能只跑对话？**

能跑后端接口，但界面因为缺图会一片空白。临时办法：把 `ui2/index.html` 里的 `<img>` 全部换掉，或者自己写个最简 HTML 指向 `/api/chat`。

**Q：素材能不能打包成种子/网盘分享？**

不建议。这是游戏的完整美术资源，分发属于侵权。这也是本仓库不放素材的原因。

**Q：我只想改模型（人设、few-shot），需要素材吗？**

不需要。改 `app/persona_core.txt` 和 `最新版/fewshot.json` 就行，但要看效果仍然需要界面素材。

**Q：自检脚本说我缺 `app/story_index.json`，要紧吗？**

不要紧，那是可选项。`python tools/build_story_index.py` 能补，但没有也能跑。

**Q：为什么解包器不放仓库？**

见 4.3。简单说：解包器本身不是问题，配套的密钥与格式说明属于规避技术措施，不适合公开。
