## 一、修掉的毛病（用户实际遇到的）

| 症状 | 原因 | 现在 |
|---|---|---|
| 全屏点了没反应 | 拆 mixin 后 `import main` 又执行一遍，拿到空壳模块 | 窗口接口统一走 `winutil._main_module()`，实机验证 3840×2160 ↔ 1024×576 |
| 回想重播慢 2~5 秒 | 重播把情绪写死成 `neutral`，和播放时的 `calm` 对不上，缓存全部 miss | 每行记住自己的情绪，重播命中缓存（0.0s） |
| 字幕两句、语音只有半句 | 合成端没问题（三组实测）；`ja_clean()` 无条件按第一个句号截断 + 句中逗号也砍 | 去掉两条截断，两句台词完整 |
| 拼错的闭标签漏进台词 | 正则只认规范闭标签 | 容错匹配，顺带修换行 bug |
| 程序日志写进 C 盘 `%TEMP%` | 日志目录默认值 | 一律写项目内，按天滚动 |
| 情绪老是 calm | 模型漏写/错写 `<emotion>` | 标签当**不可信输入**：缺失时按台词推断、明显误标会覆盖，日志记来源 |

## 二、剧情检索（`story_rag`）

- **召回修复**：闲聊不检索（意图门槛）、df 去重（`雪菜` 这类高频词不再把 idf 算成负数）、
  索引块带 `〔标题行〕`（问「轻音乐同好会再结成」也能捞到）
- **语料补全**：把特典 / 后日谈 / 赠品小说的场景并进索引（和纱相关的 41 个场景），
  索引 4915 → **8792 块 / 516.7 万字**
- **v3 三层标签**：每块带 `period`（ic / cc / coda / extra）、`route`（her / common）、
  `tags`（亲密 / 调情 / 崩坏 / 拌嘴 / 校园 / 工作 / 离别）、`title`（特典用标题）
- **按情境检索**：聊天时自动判断这句像什么情境，命中同时期 ×1.3、同情境 ×1.5，
  且同标签的块优先占位——H 场景和日常拌嘴不会混着抽
- **说话风格**：从各情境里摘她的台词，生成 `prompt/style.txt`（约 800 字）拼进人设

## 三、对话与语音

- **双语**：模型直接输出 `<ja>` + `<zh>`，字幕 = 模型自己写的中文，不再事后翻译（错配消失）
- **翻译层**：云端优先 → 本地兜底，术语表（名字/称谓）单遍替换，最长键优先（不会串词）
- **读音**：补回 `pronunciation.json`，人名按假名喂给语音
- **响度**：语音响度归一化，情绪参数按标签分组（`REF_GROUPS`）
