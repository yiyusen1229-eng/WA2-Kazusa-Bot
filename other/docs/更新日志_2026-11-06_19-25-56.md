## 一、BGM 不再只在两个曲子之间切

你反馈过：「BGM 只在寂静的冬夜和冰之刃之间切，而冰之刃该是分手争执那种沉重」。

用本机 8 个存档、476 句真实台词离线统计，根因两条：

1. 情绪走**文本正则**，「笨蛋/哼/少来/烦」这些她挂在嘴边的嘴硬被算成生气（占 11%），
   冰之刃满天飞；而真正沉重的场合**没有独立通道**。
2. 累积算法衰减太黏，calm 占八成时 warm/sad 永远翻不了身 —— 476 句只切 **2 次**。

改法：

- **优先信模型给的 `<emotion>`**：`沉重` → 冰之刃、`哭腔` → 难过、`soft/撒娇/调侃吐槽` → 温柔、
  `calm/毒舌/问句` → 平静；没有标签才回退文本规则，回退规则也分两档（嘴硬不算沉重）。
- 情绪词表**补「沉重」**，并写明「只有真的争执、说到痛处、要分开时才用」——
  词表里没有这个词，模型就没法表达沉重，冰之刃只能被嘴硬触发。
- 切换门槛：衰减 0.65→0.50、领先 2.0→1.5 分，仍然要连续两轮才换。

实测（同一批真实台词重跑新逻辑）：切换 2 → **6 次**，`warm` 会出现；真模型对
「我们到此为止吧」标 `沉重`、对「你今天怎么这么笨」标 `毒舌`。

## 二、桌面行为（置顶 / 不透明度 / 拉回本屏 / 睡眠唤醒）

菜单「画面设置」新增四项，全部走 user32 原生 API，**没有引入任何新依赖**：

| 功能 | 说明 |
|---|---|
| 窗口置顶 | 边看网页边聊时她不会被压到后面 |
| 窗口不透明度 | 100 / 90 / 80 / 70 / 60% 五档 |
| 拉回本屏 | 多显示器拔屏后窗口落在外面，一键夹回 |
| 睡眠唤醒 | 睡一觉回来音频经常哑掉 → 检测到长时间停顿就重建音频链 |

「点击穿透」做过又删了：开了之后窗口收不到任何点击，只能等倒计时或杀进程，
而这个用法（对话窗口，不是桌面挂件）根本用不到。托盘和全局快捷键也一并跳过。

## 六、模型接入层

调用模型只有一条路：`llm.generate(...)`。错误统一成 7 类（鉴权 / 余额 / 限流 / 服务端 /
离线 / 坏响应 / 其它），可重试的重试一次，必要时**回落本地模型并明确告诉你**
（「云端不可用，这一轮用的是本地模型」）——静默降级会让人以为模型突然变笨。

顺带修掉一个「假成功」：推理型模型把预算花在思考上时会返回**空正文**，
以前算成功 → 写出空摘要、界面一个字都没有。现在按坏响应报错。

预算：当天花费累加，到 80% / 超额时提示一次（默认不提醒，阈值在参数表里）。

## 七、切时期现在真的不一样了

三个时期补丁（`prompt/persona_ic.txt`、`persona_cc.txt`、`persona_coda.txt`）以前**根本不存在**，
所以切时期只是换个标签，人设一个字都不变。现在写好了：

| 时期 | 基调 |
|---|---|
| IC 高中篇 | **装做冷淡** —— 不是真冷，是怕被看穿；被戳破会慌，不是傲慢 |
| CC 大学/出道篇 | **思念成疾、朝思暮想** —— 靠钢琴和他谈恋爱，对着空气说话，一直在等 |
| CODA 成年篇 | **撒娇最多** —— 关系已确定，贴过来要抱，闹别扭但不真生气 |

（这三个文件属于角色数据，不进仓库；写法和基调表记在 `架构/03_记忆与世界书.md`。）

## 八、翻译面板不再说假话

「模型管理 → 翻译」那块以前一律显示「已连接」，但翻译根本不走它。现在按**实际在用**显示
「使用中 / 备用 / 连接」，点连接成功也只写「已保存（备用）」。板块保留，以后想试别的
翻译模型把 `translate.provider` 改成 `mt` 就会真的切过去。

## 九、本地模型的两个坑

- 内网 Ollama 改走原生 `/api/chat`，**显式带 `num_ctx`**（默认 16384）——
  OpenAI 兼容接口会把这个参数丢掉，模型就按自己参数里的窗口截断提示词。
- 上下文预算改成按**这一轮实际用的端点**选：以前配了云端 key 的人即使切到本地模型，
  也按云端 32000 的预算把全部历史发出去（实测 8500 token）。

> 说明：本地 14B 的质量拐点在 4k token 左右，这个属于模型本身的限制，已按你的意思不再优化。
