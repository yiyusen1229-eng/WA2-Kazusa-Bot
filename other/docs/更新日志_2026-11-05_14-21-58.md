# 更新日志 2026-11-05（#12 关键参数与验收指标表）

> 本轮只做**本地提交**：不 push、不改版本号、不生成补丁。角色内容不碰。

## 做了什么

一张表 + 常量集中 + 每个参数至少一条断言。

### 1. 登记表：`program/src/params.py`

47 个「调了会改变行为」的数字集中登记，每项都带：

| 字段 | 说明 |
|---|---|
| `key` | `memory.cloud_ctx` 这种点号命名，分组前缀 |
| `group` | 对话 / 记忆 / 人设·世界书 / 关系阶段 / 角色资源 / 语音 / 缓存 / 演出 / 存档·包·日志 |
| `get` | **只读**取值函数（环境变量覆盖也算进去，比如 `WA2_STAGE_EVERY`） |
| `range` | 声明区间，越界直接算自检失败 |
| `where` | 在哪改（memory.json / 环境变量 / 代码常量 / prefs） |
| `impact` / `risk` / `verify` | 影响面 / 修改风险 / 验收方式 |

这张表**不改变任何行为**：只是把「改哪些数字会动到什么」摊开。前端常量（`wt-fade.js` 的
`DEF_MS/MIN_MS/MAX_MS`）也从文件里读，不另抄一份。

### 2. 生成器：`program/tools/param_table.py`

- `--write` 生成 `other/docs/参数与指标.md`（分组表 + 派生指标 + 「怎么现场看」）
- `--check` 表过期就退出码 1（和 `arch_map.py` 一个规矩）
- 派生指标只用**仓库里的常量**算（`memory.DEFAULTS` 等），不读 `memory.json` /
  `worldbook.json` / `fewshot.json` 这些本地数据——否则换台机器 `--check` 就失败。

### 3. 常量集中（行为不变）

| 原来 | 现在 |
|---|---|
| `api_chat` 里写死的 `400` / `260` / `timeout=300` / `k=2` / `max_chars=900` | `MAX_TOKENS_CLOUD` / `MAX_TOKENS_LOCAL` / `CHAT_TIMEOUT_S` / `STORY_K` / `STORY_MAX_CHARS` |
| `api_text` 里写死的 `>= 400`（和 `main._TEXT_CACHE_MAX=2000` 对不上，实际生效的是 400） | `main._TEXT_CACHE_EVICT`，只留一个出处 |
| `persona_ctx` 里写死的 `3 / 3 / 1200` | `WB_DEFAULT_DEPTH / WB_DEFAULT_ENTRIES / WB_DEFAULT_CHARS` |
| `tts_client` 的 `timeout=120` / `timeout=60` 默认参数 | `READY_TIMEOUT_S` / `SYNTH_TIMEOUT_S` |

### 4. 自测：`program/tools/test_params.py`（51 项）

不只「有个数」，是每条关系都对：

- 结构：键唯一、字段齐全、能取到值、数值落在区间、分组都在册
- 对话：本地 token 上限 < 云端；超时 ≥30；登记值 == 模块常量
- 记忆：`budget()` 三档 **严格等于** `上下文 × 三个比例`；`trigger > recent > entries`；
  分块 < 上下文；`special_cfg.CTX_MAX == memory.DEFAULTS["cloud_ctx"]`
- 人设：三档字数上限严格递增
- 阶段：`EVERY ≥ 5`、`TAIL_ROUNDS ≥ EVERY`、`debug_state().every == EVERY`、阶段 1~4
- 语音：两个端口不同、就绪超时 ≥ 合成超时、增益方向 `max>0>min`、峰值上限为负、
  目标响度在 -30~-8、情绪参数覆盖 neutral/calm/毒舌 且四个键齐全
- 缓存/演出：淘汰阈值 ≤ 上限、过渡 `min < 默认 < max` 且默认在 200~300
- 存档/包/日志：schema ≥1、单文件上限 < 总量上限、慢请求阈值 >0、价格时效 >0
- 前端：`wt-fade.js` 里确实是 `240/200/300` 这三个字面量
- 文档：`参数与指标.md` 与 `params.py` 一致（等价于 `param_table --check`），且每个 key 都出现

## 没做 / 边界

- 表里是**代码里的值**；`memory.json` / `worldbook.json` / `fewshot.json` 是本地数据不进表，
  本机实际生效值看调试面板或 `/api/debug/state`。
- 表是生成的，不要手改；改了常量跑 `param_table.py --write`。
- 只登记「调了会改变行为」的数字；样式像素值、文件名常量、文案不进表。
- 没有做「从表反向写入代码」的配置化（那是 #19 演出/切片配置化的事）。
