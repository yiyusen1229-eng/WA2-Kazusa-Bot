## 一、改了什么

### 1. 角色切换面板（`sys_00100` / `sys_00110`）

用户反馈过三轮：压扁 → 白底 → 方块底，最后定成现在这样：

| 部件 | 做法 | 效果 |
|---|---|---|
| 底框 `sys_00100`（544×216） | 容器 `aspect-ratio: 544/216` + 图片 `100% 100%` = **等比缩放**，宽 400 → 高 159 | 四角、雪花、渐变都是原图，不拉伸 |
| 条目 `sys_00110`（480×112） | 烘成三段（`tools/bake_char_bar.py`）：左右帽 14px 原样、中间段横向拉长，高度统一 30px | 又细又长也不变形，没有透明留白 |
| 标题 / 取消 | 移到框外（上 / 下） | 不再压在边框花纹上 |
| 列表 | `overflow-y: auto` + 5px 青色滚动条（和回想同款），`justify-content: safe center` | 一屏 3 行；少角色时居中，多角色时滚动 |

### 2. 白底 / 方块底（两个坑）

- **白底**：条目是 `<button>`，浏览器默认自带浅色底（`buttonface`）。九宫格只在中间 `fill`，四角是原图的透明像素，白底就从透明处透出来 → 一整块白板。
- **方块底**：为了压白底临时加的 `background: rgba(...)` 是矩形，而条目的可视形状是带斜角的，四角就露出方框。
- 最终解法：**不用 border-image，改成三段背景图拼**（`sp_bar_left/mid/right.png`），背景透明。既没有透明留白，也没有矩形底。

### 3. 「结束游戏」点不动

原来只调了裸的 `window.close()`，WebView2/pywebview 里不保证生效。改成 `quitGame()`：

1. `window.pywebview.api.win("close")`（桥接，直接 `window.destroy()`）
2. `fetch("/api/window?action=close")`（HTTP 兜底）
3. 最后才 `window.close()`

`confirm` 不可用（返回 `undefined`）时也照关；只有明确点「取消」才不关。
