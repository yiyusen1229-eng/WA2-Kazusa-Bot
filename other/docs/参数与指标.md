# 参数与指标

> 由 `program/tools/param_table.py --write` 生成，**不要手改**。改了代码里的常量就重跑，表会跟着变。
> 用法：按分组找参数 → 看「影响面 / 修改风险」→ 按「怎么调」那一列去改 → 按「验收方式」验一遍。
> 每个参数在 `program/tools/test_params.py` 里至少有一条断言（区间 + 语义）；自检结果：全部在区间内
> 表里的「当前值」是**代码里的值**（含 `WA2_STAGE_EVERY` 这类环境变量覆盖）；`memory.json` / `worldbook.json` / `fewshot.json` 属于本地数据，不进表——本机实际生效值看调试面板或 `/api/debug/state`。

## 记忆

> 表里是 `memory.DEFAULTS`；`memory.json` 会覆盖（特别模式滑条改的就是它），本机实际生效值看调试面板「记忆」行。

| 参数 | 当前值 | 可调范围 | 影响面 | 修改风险 | 怎么调 | 验收方式 |
|---|---|---|---|---|---|---|
| `memory.cloud_ctx` 云端上下文窗口 | 32000 token | 4000 ~ 128000 | 决定什么时候切「记忆书模式」；调小会更早压缩，历史细节丢得快 | 中 | memory.json / 特别模式滑条 | special_cfg.CTX_MAX 必须等于它（test_params 断言）；面板「记忆」行 |
| `memory.local_ctx` 本地上下文窗口 | 4096 token | 1024 ~ 32768 | 本地模型实际能吃多少；填大了会发送超长请求 | 中 | memory.json | test_params 断言 < cloud_ctx |
| `memory.trigger_ratio` 触发记忆书的阈值比例 | 0.6 比例 | 0.1 ~ 1.0 | 越小越早开始压缩，省 token 但更容易丢细节 | 中 | memory.json / 特别模式滑条 | test_params 断言 budget 随它线性变化 |
| `memory.recent_ratio` 压缩后保留原文的比例 | 0.25 比例 | 0.05 ~ 0.9 | 调大：留更多原话，条目份额被挤；调小：条目变多 | 中 | memory.json / 滑条 | test_params 断言 recent < trigger |
| `memory.entries_ratio` 记忆条目占上下文比例 | 0.12 比例 | 0.01 ~ 0.5 | 调大：注入更多旧事，可能压过当前话题 | 中 | memory.json / 滑条 | test_params 断言 entries < recent |
| `memory.max_entries` 条目数上限 | 40 条 | 4 ~ 200 | 合并时超过就丢最旧的 | 低 | memory.json | 面板「记忆」行的条目数 / 上限 |
| `memory.repack_turns` 每几轮重新打包 | 6 轮 | 0 ~ 40 | 0 = 不后台重打包；太小会频繁调模型 | 中 | memory.json | test_params 断言 ≥0；日志里「记忆书：重新打包」 |
| `memory.max_new_entries` 一次打包最多产出条目 | 10 条 | 1 ~ 40 | 调大：一次压缩更细，但合并压力大 | 低 | memory.json | test_memory 系列自测 |
| `memory.chunk_tokens` 打包分块大小 | 4000 token | 500 ~ 16000 | 长历史按这个切成几块总结；太大一块可能超模型上下文 | 中 | memory.json | test_params 断言 < cloud_ctx |
| `memory.sync_chunks` 聊天时同步打包块数 | 1 块 | 0 ~ 4 | 调大：这一轮会明显变慢（在回复前做） | 高 | memory.json | 手动：超阈值后发一句，看「本轮」耗时 |
| `memory.async_chunks` 后台打包块数 | 6 块 | 0 ~ 20 | 后台做，不影响回复；调大可能和对话抢模型 | 低 | memory.json | 日志「记忆书：后台打包」 |

## 怎么现场看

1. 开着调试面板（标题栏「调试」或 Ctrl+Shift+D）发一句话：
   面板第一行起就是「这一轮提示词分段 / token 估算 / 场景 / 缓存命中」。
2. 更细的整包：`GET /api/debug/state`（只读，只回数字和标签）。
3. 改完常量跑一遍：`python tools/test_params.py` + `python tools/param_table.py --check`。
