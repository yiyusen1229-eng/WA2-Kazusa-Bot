# 03 · 记忆 / 世界书 / 人设 / 检索

> 四套东西别混：**人设**（她是谁）、**常驻记忆书**（她本来就知道的事）、
> **世界书**（关键词设定卡）、**对话记忆书**（这一局聊了什么）、**原作片段**（检索）。

## 文件分工

| 文件 | 职责 | 关键函数 |
|---|---|---|
| `memory.py` | 对话记忆书：阈值、打包、条目存储 | `DEFAULTS`、`should_repack`、`pack`、`entries` |
| `standing.py` | 常驻记忆书两段化：固定设定 + 关系摘要（阶段变化时后台刷） | `text`、`build`、`note`、`status` |
| `persona_ctx.py` | 人设正文、世界书读取与命中、时期判断 | `persona_text`、`worldbook_context`、`period_of`、`_period_overlay` |
| `persona_stage.py` | 关系阶段 1～4（每 40 轮云端判） | `current`、`classify` |
| `story_rag.py` | 原作检索（BM25，4592 块） | `memory_context`、`get_index`、`enabled` |
| `char_res.py` | 角色资源状态：人设/世界书/记忆书/语音/立绘在哪 | `memory_text`、`prompt_text`、`status` |

## 常驻记忆书（`characters/<角色>/memory/`）

两份东西：

| 文件 | 谁写 | 说明 |
|---|---|---|
| `*.txt`（或 `memory/*.md`） | 用户（特别模式导入） | 老格式：一坨固定设定，每轮原样注入 |
| `standing.json` | 程序（`standing.py`） | 两段化后的格式，存在就优先用它 |

```json
{"version": 1, "fixed": "固定设定（从 *.txt 抄来的，程序之后不再改）",
 "relation_summary": "- 已经确认关系\n- 她开始主动约你", 
 "stage": 3, "updated_at": "2026-11-05 15:20:00", "source_msgs": 88}
```

- **fixed 是用户的**：只在文件不存在时抄一次，之后程序不动；要重抄就删掉 standing.json。
- **relation_summary 只随关系阶段变化刷新**：每个阶段最多一次、阶段 1 不生成、
  失败冷却 30 分钟；失败保留旧版，不阻塞对话。
- 没有 standing.json 或文件坏了 → 回落 `char_res.memory_text()`，注入行为和以前一样。

## 对话记忆书（`memory.py`）默认值

```
cloud_ctx=32000  local_ctx=4096   trigger_ratio=0.6   recent_ratio=0.25
entries_ratio=0.12  max_entries=40  repack_turns=6  max_new_entries=10
```

> 这些数字的区间 / 影响面 / 风险 / 验收方式，以及本机是否被 `memory.json` 覆盖过，
> 看 [`参数与指标.md`](../参数与指标.md)（由 `src/params.py` 生成，`--check` 防过期）。

条目结构：`{text, kind: preference|event|progress, from: [a,b]}`；`progress` 只留最新；
`covered_upto` 是游标；每 6 轮把新折叠的一段压进 `cache/memory_runtime.json`。

## 世界书（`characters/<角色>/worldbook/worldbook.json`）

- 顶层：`scan_depth`(8)、`max_entries`(4)、`max_chars`(1200)、`entries[]`
- 条目：`{name, keywords[], content, priority, period?}`；`period` = `ic|cc|coda|all`（缺省=全放行）
- 只扫**最近 8 条消息**做关键词子串匹配，命中后按 priority 排序截断
- 结构**冻结**（用户要求不改），只加内容

## 人设（`characters/<角色>/prompt/`）

`base.txt` + `stageN.txt` 拼；时期补丁 `persona_ic.txt / persona_cc.txt / persona_coda.txt`
追加在最后并声明最高优先级。`char_res.prompt_text()` 发现 `base.txt` 就返回空
（由 `persona_ctx` 负责拼），别再各拼一套。

## 原作检索（`story_rag.py`）

- 索引 `program/src/story_index.json.gz`（4592 块 / 408 万字）
- 按角色开关：角色文件夹有 `story.json` 且 `enabled:false` → 不检索；有 `story_index.json.gz` → 用角色的
- 改检索参数：k、`max_chars`、分数门槛在 `memory_context` 里

## 坑

- 常驻记忆书是**用户手写**的文件，不要自动生成（会污染人设）。
- 世界书和记忆书**同一事实别写两处**，会双重强调。
- 时期补丁文件不存在时静默跳过（本地目前就没有这三份）。
