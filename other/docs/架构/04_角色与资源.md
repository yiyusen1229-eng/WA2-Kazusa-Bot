# 04 · 角色与资源

> 一个角色 = `characters/<角色>/` 一个文件夹，**自包含**。切角色 = 换一整套。

## 角色文件夹

```
characters/
  active.json                  {"id": "和纱"}
  <角色>/
    name.txt                   显示名
    prompt/                    base.txt + stage1~4.txt + persona_<时期>.txt
    worldbook/worldbook.json    世界书
    memory/*.txt                常驻记忆书
    voice/<情绪>/*.wav          参考音频（TTS）
    portrait/<衣服名>/<表情名>.png + index.json
    sessions/*.json             存档（按角色隔离）
    story.json                  {"enabled": false} = 这个角色不做剧情检索
    tts.json                    {gpt, sovits} 权重路径（可选）
    pronunciation.json          {"中文名": "かな"}（可选）
    opening.json                {zh, ja, emotion} 开场白（可选）
```

## 代码分工

| 文件 | 职责 | 关键点 |
|---|---|---|
| `characters.py` | 角色增删改查、目录、迁移、立绘索引合并 | `active_dir/switch/create/ensure/seed_character`、`sprite_index` |
| `char_res.py` | 角色级资源“在哪、有没有” | `memory_text/prompt_text/status/voice_one` |
| `special_files.py` | 特别模式的导入/打开/立绘落盘 | `open_target`（永远打开角色文件夹）、`save_portrait` |
| `special_cfg.py` | 角色名读写 | 走 `characters.name_file()` |
| `tts_client.py` | 语音合成、参考音频、权重 | `refs_dir()`（角色 voice/ 优先）、`_char_voice_sig` |

## 立绘（`portrait/`）

- 目录名 = **衣服中文名**（如 `礼服`、`高中·春秋JK制服`），文件名 = **表情名**（`认真/冷淡/微笑/生气/难过/惊讶/害羞`），重名加 `_2`
- `index.json`：`outfits[中文名] = {code, codes[], label, default, emotions{en:file}, variants[]}`
- 前端 `OUTFIT_BY_SCENE` 做「场景→衣服」兜底，`resolveOutfit()` 名字/编号都认
- 烘焙工具：`tools/rename_sprites.py`（改名/合并）、`tools/bake_char_bar.py`（面板条目三段）

## 语音（`voice/` + `tts.json`）

- 参考音频按情绪分目录，`refs_dir()` 角色 voice/ 优先、回落 `refs_touma`
- 权重：`tts.json` 有就用，没有走默认；`_char_voice_sig` 变了才切（同进程不重启）
- 读音替换：`pronunciation.json` → 送 TTS 前替换，界面文字不变

## 角色包（`char_pack.py`）

- 导出：只挑 `name.txt` + `prompt/ worldbook/ memory/ portrait/ voice/` → `<角色名>.zip`
  （不带 `sessions/`、`story.json`、`tts.json`、`opening.json`、`pronunciation.json`、缓存）
- zip 里带 `manifest.json`（格式名 / 版本 / 角色名 / 导出时间 / 文件数 / 字节数）
- 导入：先解到 `characters/.importing_*` → 校验 → 改名落盘（**不自动切换**），重名加序号；
  没有 manifest 的裸包也认（用 `name.txt` 或压缩包文件名当角色名）
- 界面：特别模式 → 配置角色 → 导出 / 导入（底板就是发送按钮的三态图 `btn_3state.png`）
- 安全：路径穿越 / 绝对路径 / 盘符条目丢弃；总量 2GB、单文件 512MB、条目 2 万上限

## 坑

- `ensure()`/`switch()`/`create()` 会灌种子（把自带 `persona/`、`worldbook/` 复制进角色文件夹），别绕过。
- 新角色默认 `story.json {"enabled": false}`（避免检索到别人的剧情）。
- 素材、角色资源、存档都**不入库**（`.gitignore`）；换机要跑 `check_assets.py` + 烘焙工具。
- `sessions` 目录在 `--serve-only`/自测时会被 `WA2_SESS_DIR` 覆盖，属预期。
