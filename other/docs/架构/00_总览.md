## 系统总架构（一层）

```
┌──────────── WebView2 窗口（无边框）────────────┐
│  index.html  ── 7 个界面（标题/对话/回想/存档/设置/特别/博客）
│    game.js      对话演出、打字机、立绘、回想、请求
│    special.js   特别模式：参数、角色、语音、世界书
│    opt.js       设置：模型/连接/选项
│    screens.js   界面开关、右键/ESC、通用退出
│    savepages.js 存读档
│    menubar.js   顶部菜单（场景/服装/时期/窗口）
│    uitext.js   字模图替换（中文→烘焙图）
└───────────────────┬──────────────────────────┘
                    │ HTTP（127.0.0.1:8771+）
┌───────────────────┴──────────────────────────┐
│ main.py  本地服务（HTTP + 静态文件 + 窗口控制）│
│   ├─ /api/chat        对话管线（→ 02）        │
│   ├─ /api/text /api/tts  字模渲染 / 语音合成  │
│   ├─ /api/special/*   角色资源与配置（→ 04）  │
│   ├─ /api/session/*   存读档                  │
│   └─ /game/assets/**  素材静态服务            │
└───────────────────┬──────────────────────────┘
      ┌─────────────┼─────────────┐
   云端 LLM      本地 GPT-SoVITS   本地数据
 (对话/翻译)      (语音合成)      characters/ res/assets/
```

## 三条硬规则

1. **一次只读一层**：动后端别去读 `game.js`（68 KB）全文，动前端别读 `main.py` 全文。
2. **先 `--stat` 再 `--outline` 再 `--slice`**，不要整份贴文件。
3. **验证优先用 JSON 探针**，不要截图（截图很贵）。
4. **代码落位对照 `映射表.md`**（自动生成）：新文件要登记层级、单文件不超过 400 行、
   改完跑 `python program/tools/arch_map.py --write`。
