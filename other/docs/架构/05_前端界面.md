# 05 · 前端界面

> 前端是「一张 index.html + 7 个界面 div + 一堆各自负责的 js/css」。
> 改界面先看 `index.html` 的结构，再去改对应 js，**别去读 game.js 全文（68 KB）**。

## 界面（`index.html` 里的 .uiScreen）

| id | 界面 | 主 js |
|---|---|---|
| `titleScreen` | 标题 + 主菜单 | `game.js` |
| `gameScreen` | 对话（立绘、文本框、按钮） | `game.js` |
| `blogScreen` | 回想 | `game.js` |
| `saveScreen` | 存读档 | `savepages.js` + `savetabs4.js` |
| `optScreen` | 设置（模型/连接/选项） | `opt.js` |
| `specialScreen` | 特别模式（参数/角色/语音） | `special.js` |
| `spCharPick` | 角色切换面板（特别模式内浮层） | `special.js` |

## js 分工

| 文件 | 职责 |
|---|---|
| `game.js`（68 KB） | 对话演出核心：发请求、解析标签、打字机、立绘切换、回想、滚轮/右键、翻页图标、音量 |
| `menubar.js` | 顶部菜单：场景/服装/时期、窗口按钮、拖拽 |
| `special.js` | 参数滑条、角色切换/新建、世界书/语音/立绘配置、花费预估 |
| `opt.js` | 设置页：模型、base_url、连接测试 |
| `screens.js` | `__showUIScreen/__hideUIScreen/__closeScreens/__closeTopScreen`：所有浮层的统一开关 |
| `savepages.js` | 存档网格、缩略图、页签 |
| `uitext.js` | 把中文文本换成字模图（`/api/text`） |
| `debug.js` / `zoom.js` / `scale.js` / `sound.js` | 调试面板 / 缩放 / 整数倍 / 音效 |

## CSS 分工

| 文件 | 管什么 |
|---|---|
| `game450.css` | 舞台基准（800×450）、对话界面、回想、翻页图标 |
| `screens-base.css` | 界面通用壳（顶栏、EXIT、底栏）、回想滚动条 |
| `save-screen.css` | 存读档 |
| `opt.css` / `opt-screen.css` | 设置页（内容 + 壳） |
| `special.css` | 特别模式 + 角色面板（底框 `sys_00100` 等比、条目三段烘焙） |
| `menubar.css` | 顶部菜单 |
| `unifont.css` | 字模/字体兜底 |

## 必知的三个机制

1. **字模图**：中文不直接显示，`uitext.js` 把每段文字发给 `/api/text` 换成 PNG 贴上去；
   `data-no-uitext="1"` 可关掉某个容器。
2. **?v= 缓存**：改了 css/js 要 bump `index.html` 里对应的 `?v=`，否则 WebView2 可能用旧文件。
3. **浮层开关统一走 `screens.js`**：右键/ESC 只关最上层，别在各自 js 里 `classList.remove("show")`。

## 验证（不截图）

```powershell
python program\tools\ui_probe.py --url http://127.0.0.1:8791/game/index.html `
  --js setup.js --check check.js --wait 1500
```

`--js/--check` 收**文件路径**；探针返回 JSON（节点数、高度、是否可滚、`naturalWidth>0`、报错），
用这些数字判断，**不要 --shot 截图**（一张上千 token）。
