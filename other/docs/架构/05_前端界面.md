## 必知的三个机制

1. **字模图**：中文不直接显示，`uitext.js` 把每段文字发给 `/api/text` 换成 PNG 贴上去；
   `data-no-uitext="1"` 可关掉某个容器。
2. **?v= 缓存**：改了 css/js 要 bump `index.html` 里对应的 `?v=`，否则 WebView2 可能用旧文件。
3. **浮层开关统一走 `screens.js`**：右键/ESC 只关最上层，别在各自 js 里 `classList.remove("show")`。

## 演出过渡（`wt-fade.js`，`WA2.fade`）

- **背景**：`#bgLayer` 常驻当前图，`#bgLayer2` 只在过渡时淡入；过渡结束后把新图搬回 `#bgLayer`
  （`settle()`），所以别的代码读 `#bgLayer` 永远是当前那张。两层都带同一层渐隐蒙版，
  淡化中途蒙版叠起来的透明度约等于一层，画面不会中途变亮。
- **立绘**：`#spriteGhost` 盖在 `#sprite` 上淡入新图，淡完把 `#sprite.src` 换成同一张、
  叠层归零；缺图时保留旧图并提示一次，不留破图标。
- **时机**：换图前先 `new Image()` 预载，载完才淡——否则会先闪一下未解码的空白。
- **配置**：三级来源（后者覆盖前者）：内置默认 240 → 角色 `performance.json` 的 `fade_ms`
  → `prefs.json` 的 `xfadeMs`（用户自己调过就听用户的），夹在 200~300；
  `xfade: false` = 直接切。菜单「环境设置 → 演出过渡」= `WA2.fade.set()`。改完不用刷新。
- **自测**：`tools/test_fade.js` 用假的 `document` 跑，覆盖配置夹取、双层交替、收尾搬图。

## 每角色演出配置（`wt-perfcfg.js` + `perfcfg.py`，`WA2.perfCfg`）

- `characters/<角色>/performance.json`：`{"fade_ms": 280,
  "mood_to_emotion": {"shy": "sad"}, "outfit_by_scene": {"夜の学校": "冬季校服"}}`
  ——**只写覆盖值**，没写的用模块内置表（`wt-sprite.js` 的 `MOOD_TO_EMO` / `OUTFIT_BY_SCENE`）。
- 加载时机：脚本加载时拉一次 `/api/performance`，`wt-sprite.loadIndex()`（切角色 / 启动）再拉一次。
- 配置有 warning（超范围被夹、类型不对、不认识的键）时弹一次 toast，并写日志。
- 接口拿不到 / 文件坏了：静默用内置默认，不影响演出。

## 选择分支（`wt-choices.js` + `choice.css`）

> 2026-11-05 23:16 整块重做过一次（上一版把条高压成 22、行距写成 29，看起来不像原版）。
> 细节与读数来源见 [`更新日志_2026-11-05_23-16-17.md`](../更新日志_2026-11-05_23-16-17.md)。

- 入口：输入框下面「选择分支」按钮（`#choiceBtn`，底板和发送键同一张 `ui/btn_3state.png`，三段态）
- 流程：`POST /api/choice`（带最近 8 条对话 + `prefs.choiceCount`）→ 烘好字模 → 上 DOM →
  点一条 → 整层 `.fading` 淡出 260ms → 把选项填进输入框并 `send()`
- 一条 = 五层（`.choiceRow` 是 490×45 的绝对定位盒子）：
  `choiceBg`（段1）· `choiceHl`（段2，`plus-lighter`）· `choiceSnow`（段3）·
  `choiceTag`（白牌）· `choiceTxt`（一整张字模：`"1."+选项`）
- 素材（都是**原版图**，`program/tools/make_choice_assets.py` 一条命令生成）：
  - `ui/choice/bar_off.png` ← `sys_00200` 段1（784×72）
  - `ui/choice/bar_on.png` ← `sys_00200` 段2（784×72，**高亮层**，不是替换帧）
  - `ui/choice/snow.png` ← `sys_00200` 段3（784×72，两端雪花；和条身同画布同原点，整张叠）
  - `ui/choice/tag.png` ← `sys_00011` 图集里的**小白牌**（alpha 盒 18×33）——别用 CSS 画假的
- **几何（实测，改之前先读 `choice.css` 顶部注释）**：
  条 **490×45**（= 784×72 × **0.625**，和贴图同比例，不切不拉伸）、左端 x **154.7**（水平居中）、
  上沿 y **148**、行距 **52**、字身格 **20px**、全角步进 17.5px、白牌 11.25×20.6 @条内 (56, 10.7)。
  **别再写 490×22 / 行距 29 —— 那是把高光误当条高量出来的。**
- **悬停是加法**：原版悬停条的像素 = 段1 + 段2 逐通道相加，所以 `.choiceHl` 用
  `mix-blend-mode: plus-lighter` 叠一层（`opacity` 0→1）。**雪花层同样是加法**
  （`.choiceSnow` 也 `plus-lighter`）：雪花芯色 (149,193,227)，原版常态那条最亮处 R=159
  = 149 + 条身底色，用普通 alpha 盖会发灰。`plus-lighter` 要 Chromium 111+，
  不支持时退化成普通覆盖（偏暗但不会坏）。
- **不要给条身加 `filter: drop-shadow()` 做辉光**：实测会让条子软边外面那几行**变暗**
  5~10 级（R 掉得最多），实机上就是「亮起来的时候有一圈黑边」。原版本来也没有额外辉光，
  边缘衰减就是贴图自己的 alpha 坡。
- **打开时收起输入栏**（`body.choiceOpen` → `#inputBar { opacity:0 }`）：输入栏的青色边框
  正好横穿选项条那一行，会被看成一条「分界线」。选完 / Esc 关闭时恢复。
- 文字**不走** `uitext.js`：字模在 `wt-choices.js` 里用 `/api/text?...&plain=0`（白字+2px 黑描边）
  自己烘，悬停那张再带 `color=` 染色，两层交叉淡入。行盒上有 `data-no-uitext="1"`。
  （`ui/save/d1..d9.png` 是存档界面的淡青数字、没有描边，压在亮条上看不见，别拿来做编号。）
- 3~5 条时整块以「2 条时的块心」为中心上移，并夹住不压对话框（`SAFE_BOTTOM = 318`）。
- **开着选项也能存档**：`body.choiceOpen #toolbar { z-index:78 }` 把工具栏抬到选项层（z 70）
  上面，点「存档」即可；存档界面（z 120）本来就盖得住。
  存的那一刻如果选项还开着、**一条都没选**，`__saveMeta()` 会把选项写进 `meta.choice`；
  读这个档时 `wt-session.js` 的 `restoreChoices()` 调 `WA2.choices.show(options)` 原样摆回来，
  **不再请求 `/api/choice`**。已经选过的那一层已经关了，`pendingOptions()` 给 null，所以不记。
  反例也处理了：读一个没有 `meta.choice` 的档时，手上还开着的旧选项会被收掉。
- 键盘：1~5 直接选，Esc 关掉（**吃掉事件**，不然 `wt-nav` 会顺手回标题）；
  右键退出走 `screens.js` 的 `__closeTopScreen()` → `__closeChoices()`。
- 选项数量：**标题栏「系统 → 选择分支数量」**（2 / 3 / 4 / 5 子菜单），写 `prefs.json` 的
  `choiceCount`。别塞进 OPTION 界面——那三页是烤死的图，塞不进原生控件

## 验证（不截图）

> **探针要读 `data-uitxt`，不能读 `textContent`**：正文经过字模渲染器（`WA2.text.render`）后会变成
> `<img src="/api/text?text=…">`，`textContent` 是空的，原始文字在 `data-uitxt`
> 属性里。读 `textContent` 会得到「渲染了但没字」的假象。

```powershell
python program\tools\ui_probe.py --url http://127.0.0.1:8791/game/index.html `
  --js setup.js --check check.js --wait 1500
```

`--js/--check` 收**文件路径**；探针返回 JSON（节点数、高度、是否可滚、`naturalWidth>0`、报错），
用这些数字判断，**不要 --shot 截图**（一张上千 token）。
