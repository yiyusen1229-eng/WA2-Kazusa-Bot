## 接口分组（29 个）

| 前缀 | 用途 |
|---|---|
| `/api/chat` | 对话（请求可带 `model/base_url/memory/bg/outfit/period`） |
| `/api/text` | 中文 → 字模 PNG（`uitext.js` 调） |
| `/api/tts` | 文本 → wav（`tts_client`，本地 GPT-SoVITS）。响应带 `X-Voice-Gain-DB` / `X-Voice-Lufs`（响度归一化，见 `audio_gain.py`） |
| `/api/session/{list,load,save,thumb}` | 存读档（目录 = `characters/<角色>/sessions/`） |
| `/api/special/{cfg,name,open,status,upload}` | 特别模式：参数、角色名、打开文件、状态、导入素材 |
| `/api/character/{list,switch,pick,new,opening,sprite/index.json}` | 多角色 |
| `/api/charpack/{export,import}` | 角色包导出 / 导入（zip，会弹系统窗口） |
| `/api/scene/{list,match}` | 场景 CG 匹配 |
| `/api/window` | 窗口控制（close/min/max/move/dragbegin/state） |
| `/api/modelcfg`、`/api/ollama`、`/api/prefs`、`/api/price*`、`/api/usage`、`/api/voice/ok`、`/api/ping`、`/api/log/dump` | 杂项 |
| `/api/debug/state` | 调试面板的只读状态包（`diag.snapshot()`：提示词分段 / 命中 / 缓存 / 阶段）；不触发任何计算 |

## 改接口的步骤

1. 在 §7.1 加分支（`self.path == "/api/xxx"` 或 `startswith`）；
2. 处理函数放在 §7 里对应的 7.x 段，别塞进 §0–§6；
3. 返回统一走 `self._json({...})`；
4. 前端在 `game.js` / `special.js` 里 `fetch`，记得把接口写进本文件表格。

## 密钥

- 读 key 的顺序：`WA2_API_KEY` → `DEEPSEEK_API_KEY` → `config.json` 的 `api_key`（`secret.env_key()`，由 `cloud_cfg()` 注入）。
- 环境变量优先时，`/api/modelcfg` 只返回掩码 `sk-****abcd` + `key_from_env`；界面回传掩码时 `model_cfg_save()` 保留原 key，不会把 `****` 写进文件。
- 日志（`applog.log()` / `main.log()`）写之前统一过 `secret.redact()`，抹掉 `sk-...`、`Bearer ...`、`"api_key": "..."`。

## 坑

- **只起后端**必须 `WA2_ASSETS_DIR`，否则 `/game/assets/**` 404。
- 静态文件走 Range（音频拖进度要用），改 `send_head` 时别把 Range 弄丢。
- `_window_ctl` 在 `--serve-only` 下没有窗口，会返回 `{"ok": false, "error": "窗口未就绪"}`，属正常。
- `globals()["_WINDOW"]` 是窗口句柄，别随便改名。
