## 接口分组（30 个）

| 前缀 | 用途 |
|---|---|
| `/api/chat` | 对话（请求可带 `model/base_url/memory/bg/outfit/period`） |
| `/api/text` | 中文 → 字模 PNG（`uitext.js` 调） |
| `/api/tts` | 文本 → wav（`tts_client`，本地 GPT-SoVITS）。响应带 `X-Voice-Gain-DB` / `X-Voice-Lufs`（响度归一化，见 `audio_gain.py`） |
| `/api/session/{list,load,save,thumb}` | 存读档（目录 = `characters/<角色>/sessions/`） |
| `/api/special/{cfg,name,open,status,upload}` | 特别模式：参数、角色名、打开文件、状态、导入素材 |
| `/api/character/{list,switch,pick,new,opening,sprite/index.json}` | 多角色 |
| `/api/charpack/{export,import}` | 角色包导出 / 导入（zip，会弹系统窗口） |
| `/api/scene/{list,match}` | 场景 CG 匹配 |
| `/api/window` | 窗口控制（close/min/max/move/dragbegin/state） |
| `/api/modelcfg`、`/api/ollama`、`/api/prefs`、`/api/price*`、`/api/usage`、`/api/voice/ok`、`/api/ping`、`/api/log/dump` | 杂项 |
| `/api/debug/state` | 调试面板的只读状态包（`diag.snapshot()`：提示词分段 / 命中 / 缓存 / 阶段）；不触发任何计算 |
| `/api/log/bundle?turns=N` | 生成脱敏诊断包 zip（`logpack.bundle`）；默认不含对话，`turns>0` 才带最近 N 轮 |
| `/api/performance` | 每角色演出 / 切片规则（`perfcfg.detail()`：`performance.json` + `persona_slices.json` + warnings） |
| `/api/hotreload` | 素材热重载状态（GET）/ 开关（POST `{"on":0/1}`）；前端每 4 秒问一次 `gen` |
| `/api/assets/wizard` | 素材导入向导数据（`api_wizard.build`，`?refresh=1` 现扫） |
| `/api/cleanup` | 数据清理入口（#17，`api_cleanup.py`）：`GET` 概览（各项体积 + 角色列表）；`POST /api/cleanup/cache` 按项清缓存、`/export` 打 zip（默认脱敏、不带对话）、`/character` 把角色挪进 `characters/_deleted/`（`confirm` 必须是角色名） |
| `/api/update`、`/api/update/{apply,status}` | 更新：`GET` 查远端版本并告知能不能自动更新（`auto/mode`）；`POST /apply` 后台开始一键更新；`GET /status` 轮询进度。实现见 `updater.py`：有 `.git` 走 `git fetch + reset --hard`，否则下载 codeload 的 master 快照只覆盖代码/文档白名单（见 `WL_DIRS/WL_FILES`），**不碰 `build_env/`（角色/存档/缓存/venv）、`res/`、`logs/`**；覆盖前备份到 `program/work_scratch/update_backup_<时间>/` |
| `/api/choice` | 选择分支（`api_choice.py`）：`POST {count, messages}` → `{ok, options[]}`。只看最近 8 条对话，让模型给 2~5 个玩家可选项；选项数量由界面设置 `prefs.choiceCount` 决定（默认 2，范围 2~5） |

## 改接口的步骤

1. 在 §7.1 加分支（`self.path == "/api/xxx"` 或 `startswith`）；
2. 处理函数放在 §7 里对应的 7.x 段，别塞进 §0–§6；
3. 返回统一走 `self._json({...})`；
4. 前端在 `game.js` / `special.js` 里 `fetch`，记得把接口写进本文件表格。

## 密钥

- 读 key 的顺序：`WA2_API_KEY` → `DEEPSEEK_API_KEY` → `config.json` 的 `api_key`（`secret.env_key()`，由 `cloud_cfg()` 注入）。
- 环境变量优先时，`/api/modelcfg` 只返回掩码 `sk-****abcd` + `key_from_env`；界面回传掩码时 `model_cfg_save()` 保留原 key，不会把 `****` 写进文件。
- 日志（`applog.log()` / `main.log()`）写之前统一过 `secret.redact()`，抹掉 `sk-...`、`Bearer ...`、`"api_key": "..."`。

## 坑

- **只起后端**必须 `WA2_ASSETS_DIR`，否则 `/game/assets/**` 404。
- 静态文件走 Range（音频拖进度要用），改 `send_head` 时别把 Range 弄丢。
- `_window_ctl` 在 `--serve-only` 下没有窗口，会返回 `{"ok": false, "error": "窗口未就绪"}`，属正常。
- `globals()["_WINDOW"]` 是窗口句柄，别随便改名。

### 窗口 / 桌面（`api_window.py`，`winutil.py`）

| 动作 | 干什么 |
|---|---|
| `close` / `min` / `max` / `restore` / `togglemax` / `togglefull` / `resize` | 原有窗口控制 |
| `state` | 最大化 / 全屏 **+ `topmost` / `alpha`** |
| `topmost&on=1\|0` | 置顶（`SetWindowPos` + `HWND_TOPMOST`） |
| `alpha&v=0~255` | 整窗不透明度（`WS_EX_LAYERED` + `SetLayeredWindowAttributes`） |
| `workarea` | 当前显示器工作区 + 窗口矩形 |
| `clamp` | 把窗口拉回可见区域（多显示器拔屏后救回来）|

另有 `GET /api/power` → `{ok, gen, last_gap, at, interval, jump_s, running}`：
`powerwatch.py` 每 5 秒记一次墙钟，**跳 >20 秒**就认定刚睡醒（巡检线程睡着时跑不了，
醒来第一轮必然跳），`gen` +1，前端据此重建音频。

⚠️ 坑：`SetWindowPos(HWND_TOPMOST)` 对**程序自己造、离屏未激活**的窗口不落样式位
（返回成功、`GetWindowLong(GWL_EXSTYLE)` 还是 0）。所以单元测试只验 getter，
「真的浮在最上面」由 `tools/test_desktop_app.py` 开真主窗口验。

> 「点击穿透」做过又删了（2026-11-06 用户：用不上）。它是这批里唯一有风险的
> ——开了之后窗口收不到任何点击，得配自动恢复。别再加回来，除非有「桌面挂件」那种用法。

### 导出与首次自检（`api_export.py` / `firstrun.py`，#23）

| 接口 | 干什么 |
|---|---|
| `GET /api/export/chat?slot=auto\|N&fmt=md\|txt&redact=1&only_reply=0` | 附件下载一段对话 |
| 同上 + `preview=1` | 只返回 JSON：句数 / 字数 / 脱敏处数 / 前 800 字（前端先给人看） |
| `GET /api/firstrun` | 首次自检：模型 / 角色 / 语音 / 素材 / 存档 五项，只读 |

导出的三条规矩：**默认脱敏**（密钥走 `secret.redact`、盘符路径换 `<本机路径>`）、
**先预览再下载**、**只读存档不写任何文件**。
`only_reply=1` 只导她的台词（发截图/卡片时不用手删自己的话）。
