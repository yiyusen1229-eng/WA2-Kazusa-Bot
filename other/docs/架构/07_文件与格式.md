# 07 · 数据文件与格式

> 改格式 = 要兼容旧数据。下面这些都有“读的时候不能炸”的要求。

## 存档（`characters/<角色>/sessions/<slot>.json`）

```json
{
  "slot": "1",
  "name": "存档名",
  "time": "2026-11-03 21:40",
  "messages": [{"role": "user|assistant", "content": "…", "zh": "…"}],
  "memory": { "entries": [...], "covered_upto": 123, "version": 1 },
  "meta": { "outfit": "礼服", "period": "coda", "scene": "…", "bgm": "…" }
}
```

- `memory` 是读档时的**快照**；运行时读的是 `cache/memory_runtime.json`
- `auto.json` 是自动存档；存档槽位编号是字符串
- 目录由 `sessions.SESS_DIR` 决定（默认按角色；`WA2_SESS_DIR` 可覆盖）

## 角色（`characters/`）

| 文件 | 格式 |
|---|---|
| `active.json` | `{"id": "和纱"}` |
| `<角色>/name.txt` | 纯文本一行 |
| `story.json` | `{"enabled": false}` 或 `{"index": "story_index.json.gz"}` |
| `tts.json` | `{"gpt": "路径", "sovits": "路径"}`（相对路径按 GPT-SoVITS 根解析） |
| `pronunciation.json` | `{"中文名": "かな"}` |
| `opening.json` | `{"zh": "…", "ja": "…", "emotion": "soft"}` |

## 世界书（`worldbook/worldbook.json`）

```json
{ "scan_depth": 8, "max_entries": 4, "max_chars": 1200,
  "entries": [{"name": "…", "keywords": ["…"], "content": "…", "priority": 80, "period": "all"}] }
```

## 立绘索引（`portrait/index.json`）

```json
{ "outfits": { "礼服": { "code": "013", "codes": ["030","041"], "label": "礼服",
  "default": "认真.png", "emotions": {"认真": "认真.png"},
  "variants": [{"variant": "礼服", "file": "礼服/认真.png", "emotion": "认真"}] } },
  "files": ["礼服/认真.png", "..."] }
```

## 检索索引（`program/src/story_index.json.gz`）

gzip 的 JSON 数组，每块 `{id, src(章节/日期), text}`；4592 块，中位 905 字。
重建用 `tools/build_story_index_v2.py`（很慢，别频繁跑）。

## 语音缓存（`program/cache/tts/`，每次启动清空）

| 文件 | 内容 |
|---|---|
| `<hash>.wav` | 合成结果原样（按 文本+语种+情绪+参考音频签名 命名），**永远不改写** |
| `<hash>.wav.gain.json` | 响度侧车：`{target, lufs, peak_db, gain_db, applied, bytes, at, channels, rate}` |

- `gain.json` 只记「到 -16 LUFS 要几个 dB」；增益在 `/api/tts` 发字节时应用，磁盘 wav 不动
- 侧车缺了会在下次命中缓存时补算；`bytes` 对不上（文件被换过）也会重算
- 格式不认识（不是 16bit PCM）时 `format` 标明、`gain_db` 为 0，不做任何改动

## 配置

| 文件 | 内容 | 入不入库 |
|---|---|---|
| `program/src/config.json` | 云端 key / base_url / model | ❌（`.gitignore`） |
| `prefs.json` | 界面偏好（音量、窗口、动作开关） | ❌ |
| `cache/memory_runtime.json` | 运行时对话记忆书 | ❌ |
| `logs/app-<日期>.log` | 运行日志 | ❌ |

## 坑

- 改存档字段要**向后兼容**：读不到就当没有，不要 KeyError。
- `worldbook.json` 结构已冻结（用户要求），只加条目、不加/改顶层字段。
- 所有“本地数据”都在 `.gitignore`，别手滑 `git add -f`。
