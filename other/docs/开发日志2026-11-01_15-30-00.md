## 一、存档槽显示「没有数据」——路由缩进错了一层

**现象**：存档列表接口 404，十个槽位全显示“没有数据”，但存档文件（`sessions/1.json`，9.1 KB）一直在磁盘上。

**排查**：日志里反复出现

```
GET /api/session/list -> 404  0ms
```

但 `main.py` 里明明有这条路由。最后发现是**缩进错误**：

```python
if self.path.startswith("/api/session/load"):
    q = urllib.parse.parse_qs(...)
    return self._json(session_load(...))
    if self.path.startswith("/api/session/list"):   # ← 多缩进一层，成了 return 之后的死代码
        return self._json(session_list())
```

修法：把缩进改回 8 格。

**教训**：按行号插入代码时，必须同时核对缩进层级；`ast.parse` 只能查出语法错误，查不出“死代码”。

## 二、语音模型连不上——`tts_infer.yaml` 路径被写成转义序列

**现象**：模型管理显示“已连接”，但完全没声音。

**排查**：直接打 GPT-SoVITS 服务（绕过我们的程序）：

```
GET /tts?... → 500 Internal Server Error（0.00 秒）
```

0 秒就 500，说明不是推理慢，是一进函数就抛异常。查 `tts_infer.yaml`：

```yaml
t2s_weights_path: "E:\\IDM\\u4E0B\\u8F7D\\...\\Touma_Kazusa-e15.ckpt"
```

中文路径被写成了 `\uXXXX` 转义，而且用反斜杠续行折成两行。

**修法**：改成明文正斜杠路径：

```yaml
t2s_weights_path: "E:/IDM下载目录/.../GPT_weights_v4/Touma_Kazusa-e15.ckpt"
```

修复后服务日志：

```
Loading VITS pretrained weights ... <All keys matched successfully>
Loading BERT weights from .../chinese-roberta-wwm-ext-large
```

端到端验证：`/api/tts?text=テスト&lang=ja` → **200，86,444 字节，3.2 秒**。

**顺带发现**：`/api/voice/ok` 只检查服务在不在，不检查能不能合成，所以会出现“显示已连接但没声音”。

## 三、固定字模静态化

**问题**：所有文字都走 `/api/text` 实时渲染，每次点击按钮都会重新生成 PNG，中间有几帧是空的，视觉上会“闪一下”。

**方案**：

1. `tools/bake_ui_text.py` 把固定文案一次性渲染成 PNG
2. 前端直接 `<img src="assets/ui/text/xxx.png">`

生成的 26 张（`res/assets/ui/text/`）：

| 分组 | 文案 |
|---|---|
| 模型管理 | 聊天/语音/翻译模型、端点、API 密钥、模型名称、切换模型、连接、已连接、连接失败 |
| 存档提示 | 存档已保存、这个槽位没有存档、对话不足两条，不能存档、读档失败、这个槽位读不出来 |
| 覆盖确认 | 存档将被覆盖。 / 确定吗？ |
| 对话按钮 | 动作：、开、关、发送 |

**关键细节**：`动作：` 是固定标签，`开/关` 单独两张图 —— 切换时只换值那张，标签纹丝不动：

```js
var v = btn.querySelector("img.val");
if (v.dataset.baked !== k) { v.dataset.baked = k; v.src = ".../" + k + ".png"; }
```

### 尺寸换算（踩了两次坑）

字模渲染器参数固定：`FONT_SIZE=28`、描边 2px、出图高 32px。

所以图片显示高度 = **正文字号 × 32 / 字形实际高度**：

| 位置 | CSS 字号 | 实测字形高 | 显示高度 |
|---|---|---|---|
| 存档提示 / 确认框 | 15px | 30~31px | **15.5px** |
| 模型管理标签 | 11~12px | — | 12~13px |
| 对话按钮 | 7.6px | — | 8.5px |

第一次写 18px（偏大约 16%），第二次 17.1px（还偏大约 10%），最后实测字形边界才定到 15.5px。

## 七、没做成的：换页动画

原版切换存档页/OPTION 页时是**交叉缩放淡入淡出**（旧页收缩虚化、新页从略大收缩实化，约 390ms）。

**实测结论**：在这台机器的 WebView2 上，对 DOM 元素做 `transform` / `filter` 过渡**完全无效**：

| 属性 | 结果 |
|---|---|
| `opacity` | ✅ 能采到 12 个渐变值 |
| `transform` transition | ❌ 恒为 `matrix(1, 0, 0, 1, 0, 0)` |
| `transform` @keyframes | ❌ 同上 |

已排除：缓存、内联样式压制、写法问题、元素不可见。推测是多层绝对定位 + 父层 opacity 过渡导致合成层把 transform 动画丢弃。

**下一步方向**：canvas 快照 —— 先把该区域截图成位图，再对位图做缩放淡入淡出，绕开多层合成。
