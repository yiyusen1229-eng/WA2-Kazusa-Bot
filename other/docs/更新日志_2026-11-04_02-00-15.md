# 更新日志 2026-11-04_02-00-15

> 新功能：**启动自动检查新版本**，有新版本时在标题栏弹出可点击的通知。
> 补丁：`other/docs/patches/2026-11-04_02-00-15_更新补丁.patch`（基线 `8542abd`）。

## 一、怎么工作

```
启动 → 1.2 秒后 GET /api/update
        └─ 后端拉 https://raw.githubusercontent.com/<repo>/master/version.json
            └─ 比较版本号（YYYY-MM-DD.N）
                ├─ 不新：什么都不显示
                └─ 更新：标题栏右侧出现「发现新版本 x · 点此更新」
                          └─ 点击 → GET /api/open_url?url=… → 系统浏览器打开补丁页
```

## 三、发布时必须同步的两个版本号

- 仓库根 `version.json` 的 `version`
- `program/src/version.py` 的 `VERSION`

两处不一致 → 客户端要么永远不提示，要么把自己当成旧版。这条已写进 `AGENTS.md`。
