## 一、最高优先级：**存档界面不可用**

### 现象

1. 打开存档界面，10 个槽位**全部显示「没有数据」**
2. 存档时弹「存档已保存」，但读档点同一个槽显示「这个槽位没有存档」
3. **调试面板里完全没有 `LIST` 行**（我加的日志一条都没出现）

### 已查清：后端是好的

```
$ program/build_env/venv/Scripts/python -c "import sessions; print(sessions.session_list())"
DIR   = ...\program\build_env\sessions
slots = ['1', '6', '7', '8', 'auto']
```

磁盘存档都有效：

```
1.json  msgs=2  thumb=True  bg=classroom
6.json  msgs=4  thumb=True  bg=classroom
7.json / 8.json / auto.json
```

`main.py` 路由与导入都在（323 行导入、848 行路由）。

### 关键线索：日志一条没打

`fetchList()` 里加了 `__dbg("LIST", "HTTP " + r.status)` 和 `.catch` 里的 `__dbg("LIST!")`，
**重启后一条都没有**。

→ 说明 **`fetchList()` 根本没被调用**，甚至 `savepages.js` 的 IIFE 在绑定前就退出了。

而界面上那些「没有数据 / Date / First Sentence」很可能是 **`sys_01010` 图集里的静态底图**，
不是 JS 画的——**JS 完全没生效**。

### 下一步查法（按顺序）

1. 在 `debug.js` 顶部加：`__dbg("BOOT", "savepages=" + (typeof window.__renderSaveSlots))`
   - `undefined` → savepages.js 没加载 / IIFE 抛错
   - `function` → 是没被调用，查 `screens.js` 的 `__openScreen('save')` 分支
2. 给 `savepages.js` 的 IIFE 包一层 `try/catch`，把异常打到面板
3. 检查 `index.html` 里 `savepages.js` 的 `<script>` 是否还在、`?v=` 是否最新

### 已排除

- ❌ 路由缩进错误（已修，现在正确）
- ❌ 后端抛异常（直接调模块正常）
- ❌ 存档内容为空（文件里有 2~4 条消息）
- ❌ 重复绑定写 8 次（已加幂等 + 防抖，但仍无反应 → 说明 JS 压根没跑）

## 五、环境坑（很重要）

1. **测试服务起不来**：`--serve-only` 启动后进程活着但端口不监听，`curl` 返回 000。
   这一整轮因此无法自测。**替代**：`build_env/venv/Scripts/python.exe -c "import sessions; ..."` 直接调模块。
2. **改前端必须 bump `index.html` 的 `?v=`**，否则浏览器吃旧缓存。
3. **调试面板**：左上角绿字，`Ctrl+Shift+D`。只留 18 行。
   `log()` 是主 IIFE 内部函数，外部调用会 ReferenceError，要用 `window.__dbg()`。
4. **PowerShell 对中文和引号很脆**：改代码用 `edit` 工具或 Python 脚本，别用 `string.Replace` 拼多行中文。
5. **按行号插代码必须回读确认缩进**，`ast.parse` 通过不代表对（曾把整条路由变成死代码）。
6. **拆模块后所有 `globals()` 都会失效**，主模块名是 `__main__` 不是 `main`。
