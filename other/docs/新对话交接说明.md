## 二、怎么跑

```powershell
# 正常启动（会先同步 src → build_env，再开窗口）
program\启动程序.bat

# 只起后端（调接口 / 自测用）。注意要指素材目录：
cd program\build_env
$env:WA2_ASSETS_DIR = "E:\...\program\res\assets"
.\venv\Scripts\python.exe main.py --serve-only --port 8791
```

- `--port` 真的生效了；不指定则 8771 → 8772 → 随机

- 前端改动后：`Copy-Item src\ui\* build_env\ui2\ -Force -Recurse` **并且 bump `index.html` 里的 `?v=`**

## 七、已知的坑（完整版见 `重要参考_踩坑记录.md`）

今天新增的三条：

1. **素材不要复制两份**：`ui2/assets` 曾经是 `res/assets` 的整份复制（207MB），
   现在用 `WA2_ASSETS_DIR` 直连 `res/assets`。改 `run_dev.py` 时别再把 copytree 加回来。
2. **隐藏窗口后回不来**：右键功能默认是「存档」，隐藏状态下右键会去开存档界面（而它也被藏了）。
   现在左键/右键都先"叫回界面"。改隐藏逻辑时别忘了这两条恢复路径。
3. **字模接口默认每行 20 字**、且拉丁字母会被 28px 网格撑开。
   固定文案和数字请用 `tools/bake_cost_ui.py` 那种 PIL 排版烤图，别走 `/api/text`。

另外三条老坑，今天又差点踩：
- `transform` 在这台机器上连静态值都被丢弃，动画只能用 `zoom` / `filter` / `opacity`
- 改完 class 立刻读 `getComputedStyle().opacity` 拿到的是**过渡前**的值
- 样式表里的 `!important` 会压过普通内联样式（要用 `setProperty(..., "important")`）
