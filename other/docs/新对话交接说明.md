## 二、怎么跑

```powershell
# 正常启动（会先同步 src → build_env，再开窗口）
program\启动程序.bat

# 只起后端（调接口 / 自测用）。注意要指素材目录：
cd program\build_env
$env:WA2_ASSETS_DIR = "E:\...\program\res\assets"
.\venv\Scripts\python.exe main.py --serve-only --port 8791
```

- `--port` 真的生效；不指定则 8771 → 8772 → 随机

## 三、自测

```powershell
# 打开界面、执行一段 JS、读结果、截图（真实 WebView2）
python tools\ui_probe.py --url http://127.0.0.1:8791/game/index.html `
    --js setup.js --check check.js --wait 1500 --shot out.png
```

- `--js` 打开后执行（点按钮、改状态）；`--wait` 等多久；`--check` 等一下再执行（读数）
- 两个 JS 文件都要用 **IIFE** 包一层（`(function(){ ... })()`），顶层 `return` 会报语法错误
- 探测窗口标题用 `--title` 换一个，避免抓到上一次的窗口

**像素比对**（改样式后最有效的手段）：

```python
from PIL import Image, ImageChops
a = Image.open("before.png").convert("RGB"); b = Image.open("after.png").convert("RGB")
d = ImageChops.difference(a.crop((0,120,a.width,a.height)), b.crop((0,120,b.width,b.height)))
print(sum(1 for p in d.convert("L").point(lambda v: 255 if v > 8 else 0).getdata() if p))
```

上一轮就是用这个确认「删掉八九百行 CSS/JS 之后 OPTION 界面 0 差异」的。**改视觉相关代码，尽量顺手截一张基线图。**

**两个自测坑**（都遇到过）：

1. 探针窗口偶尔只有 `391×66`（抓到了窗口收起状态的整窗）——重跑一次就好，别以为是页面坏了。
2. 标题栏是自动隐藏的，`__openSpecial()` 之后立刻截图会拍到菜单栏压住顶栏。
   在 `--js` 里连点几次 `menuBar.classList.add("mbHidden")`（间隔几百毫秒）更稳。

## 六、特别模式：实现要点（下次改它先看这段）

**布局**（800×450 舞台坐标）：两栏 `.spCol` 顶部 `top:124`，左栏 `left:90 width:300`，右栏 `left:460 width:260`。

**滑条**：`sys_00030` 是竖版滚动条精灵，`make_special_ui.py` 转成横向三张图
（`assets/ui/special/slider_track.png` / `_hover` / `slider_knob.png`）。
滑块 19×19 生成、显示 10×10；轨道高 14；滑块中心离两端 8px（`KNOB_PAD`），上下各留 2px。

**恢复默认按钮**：从 `sys_03030` 裁掉左边的 "DEFAULT"，只留按钮本体（`reset_btn.png`，3 帧 142×24），
CSS 用 `background-size:100% 300%` + `0/50%/100%` 三档。

**配置项底框**：`sys_04100` 四帧图集（`background-size:100% 400%`）——
常态第 3 帧（`66.667%`）、悬停叠第 4 帧黄框（`100%`）、按下第 2 帧（`33.333%`）+ 黄框保留。
文字用 flex 垂直居中（**别用 `position:absolute; top:Npx`，会被行高带偏**，实测上 6 下 2）。

**字模**：整屏固定文案都烤在 `assets/ui/text/sp_*.png`（`bake_ui_text.py sp_`）。
数字和字母**不要重烤**：读数用现成的 `cost_d0~d9`、`cost_yen`、`cost_dot`、`cost_token` 拼；
只有 `%` `=` `≈` 是 `sp_pct / sp_eq / sp_approx`。
**尺寸坑**：`cost_*` 的字身只占画布 62.5%，`sp_*` 占 87.5% —— 所以读数里数字显示 16px、符号 12px 才等高。

**接口**：

| 接口 | 作用 |
|---|---|
| `GET/POST /api/special/cfg` | 读写 `memory.json`（`cloud_ctx` / `trigger_ratio` / `recent_ratio` / `entries_ratio`），无文件时按默认值生成 |
| `GET/POST /api/special/name` | 读写 `char/name.txt`（最长 12 字） |
| `POST /api/special/upload?kind=..&name=..` | 原始字节流落盘；`kind ∈ portrait/prompt/worldbook/memory/voice` |

**资源规则**：

- `portrait`：文件名必须是 `kaz{衣服3}{变化3}.png`，按前 3 位进 `assets/sprites/<衣服>/` 并登记 `index.json`
- 其它四类进 `char/<kind>/`，只保留最新一份；类型白名单 + 25MB 上限 + 文件名清洗
- 这些目录都在运行时目录里，不进仓库（`.gitignore` 有 `char/`、`memory.json`）

## 八、踩坑（完整版见 `重要参考_踩坑记录.md`）

**这一轮更新的三条：**

1. **「transform 在这台机器上不可用」是误判**（踩坑记录第 13 条要改）。
   真正原因是调用方在同一帧把 inline `transition` 又改成了 `opacity 220ms ease`，把 transform 的过渡声明覆盖掉了。
   复测：带 `fitStage` 父层 transform 的结构里，transform 过渡能跑出 12~13 个渐变值。做换页动画可以放心用。
2. **字模的字母数字被 28px 全角格撑开**。`/api/text` 新增 `tight=1`（半角走 16px 步进），`32000` 从 144px 缩到 84px。
3. **底框里的文字居中要用 flex**。`position:absolute; top:Npx` 会被行内字模图的行高带偏（实测上 6 下 2）。

**老坑仍在：**

- 素材不要复制两份（`WA2_ASSETS_DIR` 直连 `res/assets`，别把 copytree 加回来）
- 隐藏窗口后回不来：左键/右键都要能叫回界面
- 字模接口默认每行 20 字；固定文案和数字优先烤图
- 样式表里的 `!important` 会压过普通内联样式（要用 `setProperty(..., "important")`）
- 改完 class 立刻读 `getComputedStyle` 拿到的是过渡前的值
- 按行号插代码要回读缩进（`ast.parse` 查不出 `return` 之后的死代码）
