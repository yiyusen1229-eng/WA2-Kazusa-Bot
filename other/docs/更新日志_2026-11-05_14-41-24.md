## 顺手修的真问题：立绘接口的绝对路径穿越

写 B4 用例时发现 `characters.sprite_file()` 只挡了 `..`：

```python
os.path.join(base, "C:", "Windows", "win.ini")   # → "C:/Windows/win.ini"
```

带盘符的 `rel` 会把 base 整个甩掉，于是 `/api/character/sprite/C:/Windows/win.ini`
能把本机任意文件发出去。现在：`..`、以 `/` 开头、带盘符的一律拒绝，另加 `_under()`
在解析后确认仍在基目录下。
