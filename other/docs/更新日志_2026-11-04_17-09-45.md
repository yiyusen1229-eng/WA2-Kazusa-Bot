# 更新日志 2026-11-04 17:09:45 · 角色包导出 / 导入

> 版本不变（仍是 `2026-11-04.2`，没发版）· 基线 `648207a`
> 一句话：特别模式的角色配置区多了「导出 / 导入」两个按钮，角色可以打包成 zip 带走、换台机器直接导入。

## 做了什么

| 功能 | 说明 |
|---|---|
| 导出 | 点「导出」→ 弹出角色列表（复用切换面板，标题变成「选择要导出的角色」）→ 选一个角色 → 选保存目录 → 生成 `<角色名>.zip` |
| 导入 | 点「导入」→ 系统选文件窗口（只列 `.zip`）→ 确定 → 自动解成 `characters/` 下的新角色，**不自动切换** |
| 按钮 | 底板直接复用对话界面发送按钮的三态图 `btn_3state.png`，标签走 `/api/text` 字模，和「切换角色 / 新建角色」同一套 |

## 包里有什么

只带「换台机器也能直接演」的东西：

```
manifest.json      格式名 / 版本 / 角色名 / 导出时间 / 文件数 / 字节数
name.txt           显示名
prompt/            提示词（base + stage1~4 + persona_*）
worldbook/         世界书
memory/            常驻记忆书
portrait/          立绘 + index.json
voice/             参考音频（TTS 音色）
```

**不带**（都是有意的）：

- `sessions/` —— 对话存档不跟着包到处跑
- `story.json` —— 剧情索引是本机生成的，别人拿了也用不了
- `tts.json` —— 权重是绝对路径，换机必失效
- `opening.json` / `pronunciation.json` —— 可选小配置，不算角色本体
- 任何缓存

## 导入是怎么处理的

1. 先解到 `characters/.importing_<毫秒>`（和角色目录同一个盘，最后一步是原子改名）
2. 校验：只认 `name.txt` / `prompt/` / `worldbook/` / `memory/` / `portrait/` / `voice/`，其它条目跳过并在返回里报告
3. 角色 id：`manifest.id` > 包里的 `name.txt` > 压缩包文件名；重名自动加序号（和纱 → 和纱2）
4. 落盘后：没有 `name.txt` 就补一个；`prompt/` 是空的就用自带模板铺一份（免得导入后是个空角色）
5. 失败不会在 `characters/` 里留下半个角色（临时目录在 `finally` 里清掉）

支持两种包：正规包（`prompt/` 在根）和「把整个角色文件夹压进去」的包（`和纱/prompt/...`，会自动剥掉包装层）。

## 安全

- 路径穿越（`../../x`）、绝对路径（`/x`）、盘符（`C:/x`）条目一律丢弃
- 总量 2GB、单文件 512MB、条目 2 万上限（防解压炸弹）
- 不是 zip / 空包 / 坏包都给明确报错
- 导出时 PNG / JPG / WAV 等已压过的媒体用 `STORED`，不再白压一遍（实测 104MB 角色包 0.2 秒）

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/charpack/export` | body `{"id": "和纱"}`；弹选目录窗口 → 打包。取消返回 `{"ok": false, "cancelled": true}` |
| POST | `/api/charpack/import` | 弹选文件窗口 → 导入。同上 |

两个接口都是**阻塞式**的：系统窗口开着的时候前端那个 `fetch` 一直等着，关掉才返回。放在 `ThreadingHTTPServer` 的独立线程里，界面不卡。

## 怎么用

1. 进「特别模式」→ 右边「配置角色」→ 点 **导出** → 选角色 → 选目录
2. 把 `<角色名>.zip` 发给别人 / 拷到另一台机器
3. 对方点 **导入** → 选这个 zip → 角色列表里就多一个（要切过去自己点「切换角色」）

## 边界 / 已知取舍

- **不打包存档**：分享角色不会把聊天记录带出去，但反过来也不能靠角色包搬家存档。
- **不打包 `tts.json`**：对方的权重路径和你不一样，导过去也是错的；要换音色就自己重新导参考音频。
- **立绘靠 `portrait/index.json`**：包里有它就能正确认衣服 / 表情；手工做的裸包缺它时，立绘会落到「其他」。
- **导入不自动切换**：避免正在聊天时被换人；要立刻用就再点一下「切换角色」。
- 导出目录会记住（`char_pack.json`，和 `prefs.json` 一个位置），下次直接落在那儿。
