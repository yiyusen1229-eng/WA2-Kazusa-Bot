## 二、能直接看的

### `.tga`（2,904 个）

Truevision TGA，老式游戏最常用的图片格式，支持 alpha 通道。

- Windows 自带的照片查看器**打不开**
- 用 [IrfanView](https://www.irfanview.com/)、[XnView](https://www.xnview.com/) 可以看
- 或者用本仓库的预览器转成 PNG：

```bash
python tools/preview_assets.py game_pak/out_grp
```

### `.bmp`（206 个）

标准位图，双击就能看。游戏里多用在不需要透明的场合。

## 三、不能直接看的（重点）

### `.amp`（42 个）—— 查表数据，不是图

```
文件: b000100.amp
大小: 1280 字节
内容: 00 01 02 03 05 06 07 08 09 0A 0C 0D 0E 0F 10 11 …
末段: … F8 F9 FA FB FC FD FE FF
```

**结构**：1280 字节 = **5 张 256 项的查找表**。每张表把 0~255 的输入映射到 0~255 的输出，单调递增。

**用途推测**：渐变 / 调色 / 特效强度曲线。`b000100` 这种命名（0001 组、00 号）像是「效果参数表」。

**怎么看**：不是图，画不出来。如果要用，得知道游戏里哪段代码读它。

### `.psh`（少量）—— 像素着色器源码

```
文件: pf00.psh
大小: 119 字节
内容:
  ; パターンフェード
  ps.1.1

  tex  t0
  tex  t1

  mov  r0, t0
  add  r0.a, t1.a, c0.a    // 最も閾値の高いピクセルフェード
```

**是文本**（Shift-JIS 编码），DirectX 8 时代的像素着色器汇编。`ps.1.1` 就是版本号。

**怎么看**：用 VSCode / 记事本以 Shift-JIS 编码打开。记事本保存时容易转成 UTF-8，建议用 VSCode。

**用途**：游戏的转场特效（这里是「图案淡入淡出」）。

### `.ani`（10 个）—— 动画容器

```
文件: page_01.ani
大小: 8,720 字节
头:   49 4E 41 53 …   (ASCII "INAS")
```

头部后跟着若干 DWORD：

```
0, 0, 0, 0xCCCCCC01, 60, 120, 1, 1
```

`60 / 120` 可能是宽高，`1` 是帧数。文件名 `page_01.ani`、`塉640x360.ani` 也提示是「翻页动画」。

**怎么看**：不能直接看。格式没有完整逆向出来，里面的帧数据可能是独立编码的。

**能确认的**：这不是图片，Pillow / IrfanView 都打不开。

### `.bnr`（605 个）—— 滚动文本容器

```
文件: 1001.bnr
大小: 1,513 字节
头:   E9 05 00 00   F8 22 00 00   FF 'LSCR' 14 00 00 00 …
```

第一个 DWORD `0x000005E9` = 1,513 = **正好等于文件长度**，说明开头是长度字段；
接着出现 `LSCR` 标记（可能是 `RCSL` 倒序，scroll 的变体）。

**推测**：游戏的「バナー」（banner，滚动提示文字）数据，含文本与显示参数。605 个对应 605 条提示。

**怎么看**：不是图。可以用十六进制工具看，或按 Shift-JIS 解码试试有没有日文。

### `.spi`（127 个）—— MZP 容器

```
文件: axald.spi
大小: 41,472 字节
头:   4D 5A 50 00 'MZP'  02 00 00 00  04 00 0F 00  FF FF 00 00  B8 00 00 00
```

`MZP` 魔数 + 一组参数。文件名 `axald`、`AXALICE`、`axarchive` 像是角色/存档相关。

**怎么看**：不能直接看。可能是精灵帧或压缩数据，未逆向。

### `.scc` / `.fmt` / `.chm` —— 跟游戏无关的残留

| 扩展名 | 是什么 |
|---|---|
| `.scc` | Visual SourceSafe 的版本控制文件（开发时的残留） |
| `.fmt` | 3DS Max 的格式描述文件（同样残留） |
| `.chm` | Windows 帮助文档 |
| `.dll` / `.exe` | 引擎与工具程序，**不要乱运行** |

这些可以直接忽略。

### `.txt`（742 个）/ `.pak`（22 个）

- `.txt`：剧本、配置、说明，直接看
- `.pak`：打包文件，需要对应工具解开（`gcn.pak` 就是汉化补丁的包）

## 四、怎么批量看图片

仓库里带了一个预览器：

```bash
# 转成缩略图并生成可翻的 HTML 画廊
python tools/preview_assets.py game_pak/out_grp

# 输出到 out_grp_preview/
#   thumbs/     缩略图（PNG）
#   index.html  按文件夹分组的画廊
#   report.txt  格式清单 + 无法识别文件的头部信息
```

参数：

```bash
--max 512      缩略图最长边（默认 320）
--limit 200    只处理前 200 张（调试用）
--out 目录     指定输出位置
```

画廊是纯静态 HTML，双击就能开，不需要服务器。点缩略图看原尺寸。

**实测**：`out_grp` 里 571 张图全部成功转换，0 失败。

## 五、给「想看全部」的人

`.tga` 数量最多，但真正有意思的是**图集**：一张图里排着很多小图（按钮的三种状态、对话框的九宫格）。
这类文件适合按用途归类，而不是一张张翻。

已知对应关系（本项目用到的）：

| 文件 | 内容 |
|---|---|
| `sys_01000.tga` | 对话界面顶栏 |
| `sys_03000.tga` | 设置界面顶栏 |
| `sys_03010.tga` | PAGE 条（含三个标签的底） |
| `sys_03011.tga` | OPTION 表 1/2/3 × 高亮/悬停/常态，3×3 格 |
| `sys_03020.tga` | 翻页条（箭头 + 上一页/下一页） |
| `sys_03040/41/42.tga` | 设置界面的分组框（944×216 / 944×120 / 944×24） |
| `sys_04010.tga` | 雪花 logo（WHITE ALBUM 2 标志） |
| `sys_09000.tga` | 底栏 |
| `sys_00032.tga` | 回想界面顶栏 |

剩下的可以靠预览器自己翻。
