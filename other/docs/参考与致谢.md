### 1.1 对话模型（最终采用）

**参考到的关键信息：**

- 参数规模：Flash 552B 骨干 / 8B 预填充激活 / 16B 解码激活；Pro 1.6T / 49B 激活
  → ✅ [ofox.ai 参数解读](https://ofox.ai/zh/blog/deepseek-v4-1-flash-total-active-parameters-memory/) · ✅ [百炼 Flash 页](https://www.alibabacloud.com/help/zh/model-studio/deepseek-v4-1-flash)
- 官方支持的模型名只有 `deepseek-flash` 和 `deepseek-v4-pro`（传 `deepseek-v4.1-flash` 会报 400，错误信息里列出了合法名字）
- 定价（每百万 token，忙时）：Flash 输入 $0.30 / 输出 $1.20；Pro 输入 $1.32 / 输出 $3.96
  → 这个差价直接决定了选 Flash
- `deepseek-v4-pro` 默认开启思考模式，会用 `max_tokens` 额度跑推理，导致 `content` 为空
  → 解决办法：请求体加 `"thinking": {"type": "disabled"}`

## 二、软件与库

### 2.1 运行时与打包

| 项目 | 用途 | 来源 |
|---|---|---|
| **pywebview** | 无边框原生窗口 + 内嵌浏览器 | 🔗 [pywebview.flowrl.com](https://pywebview.flowrl.com/) |
| **WebView2**（Microsoft Edge） | 实际渲染引擎 | 🔗 [Microsoft WebView2 文档](https://learn.microsoft.com/microsoft-edge/webview2/) |
| **PyInstaller** | 打包成单 exe | 🔗 [pyinstaller.org](https://pyinstaller.org/) |
| **Python 3.10+** | 后端运行时 | 🔗 [python.org](https://www.python.org/) |

**影响：**

- `pywebview` 的 `easy_drag=False` 必须开——否则拖历史面板的滚动条会拖动整个窗口
- PyInstaller `--onefile` 会把 `ui2/` 解包到 `_MEIPASS`，所以**用户可改的文件（config.json）必须放 exe 同目录**，不能放 `BASE`（= `_MEIPASS`）
- WebView2 会按 URL 缓存 CSS/JS → 构建前必须给所有静态资源重打版本号

### 2.3 推理与本地服务

| 项目 | 用途 | 来源 |
|---|---|---|
| **llama.cpp** | 跑翻译模型 GGUF | 🔗 [ggerganov/llama.cpp](https://github.com/ggerganov/llama.cpp) |
| **Ollama** | 本地对话模型（备用路径） | 🔗 [ollama.com](https://ollama.com/) |

**影响：**

- `main.py` 保留了回退到 Ollama 的分支：`config.json` 没填 key 时走 `127.0.0.1:11434`

### 2.4 图像处理

| 项目 | 用途 | 来源 |
|---|---|---|
| **Pillow (PIL)** | 图集切图、合成、等比缩放、亮度键控 | 🔗 [python-pillow.org](https://python-pillow.org/) |
| **NumPy** | 像素级测量（找内容包围盒、量坐标） | 🔗 [numpy.org](https://numpy.org/) |

**影响：**

- 界面对齐的调试工具全部基于这两个库（渲染预览图、量元素位置）
- 从 TGA 图集切图后要做**亮度键控**（暗像素转透明），否则会带黑底

### 2.5 字体
