## 一、剧情检索（`story_rag`）召回修复

**现象**：问「学园祭的演出」「雪菜的车祸」→ 0 命中；问「浮气线里为什么要分手」→ 正常。

**两个根因**
1. `_idf_of` 拿倒排表长度当 df（那是**出现次数**）。高频词 `df=22190 > N=4592`，
   idf 算成 **−1.58**，等于把自己从检索里注销。
2. 严格档要「≥2 个 idf≥3 的词」，而 `学园祭的演出` 的二元组 idf 全在 2.4~3.5 → 一条都不给。

**改法**
- df 按文档去重数分组（倒排表按 doc id 升序，数分组即可）。
- 严格档落空时退一档：≥1 个词 + 门槛 ×0.7（只在不命中时生效）。
- 索引块加 `〔标题行〕`：场景首行像标题就用它，否则章节日期；重建 4592 块 / 0.84 MB / 写盘 0.3 秒。
- 加 `STORY_HINTS` 意图门槛：话里没有 记得/以前/结局/学园祭/车祸/第二音乐室/毕业… 就不检索
  （df 修好后「今天好冷」本来会命中 900 字剧本）。

## 二、回复标签宽容（`text_parse`）

闭标签放宽到 `</?\s*emo[a-z]*[^>]*>`。顺带发现 `ja_clean` 写的是 `split("\\n")`
（字面反斜杠+n）——真换行切不开、多行回复被字符过滤拼成一句，已改。
