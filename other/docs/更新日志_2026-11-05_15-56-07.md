# 更新日志 2026-11-05（#20 素材向导 + 热重载）

> 本轮只做**本地提交**：不 push、不改版本号、不生成补丁。角色内容不碰。

## 做了什么

### 1. 素材热重载（不用重启就能换图）

`program/src/hotreload.py`：

- 每 2 秒 stat 一遍「素材根目录 + 当前角色目录」（几百个文件，毫秒级；不装 watchdog）。
- 签名 = 文件数 + 最大 mtime + 总字节；变了以后**等稳定 0.8 秒**才动手——正在拷一张大图时
  文件大小一直在变，不等稳定就会加载到半张图。
- 触发时按名字调勾子：字模缓存失效、`char_res` 缓存清空、重写 `asset_report.json`。
  **单个勾子失败只记 WARN，别的照跑，素材保持旧图**。
- `WA2_HOTRELOAD=0` 或 `POST /api/hotreload {"on":false}` 关掉。
- `main._log_request` 不再记录 `/api/hotreload`（前端 4 秒问一次，会把日志刷满；慢请求仍记）。

前端 `ui/wt-hotreload.js`：每 4 秒问一次 `gen`（页面隐藏时不问），变了就
`WA2.assetsVer + 1`（立绘与背景 URL 带 `?v=` 绕过 WebView2 图片缓存）
→ 重拉立绘索引 → 重画当前立绘与背景 → 提示一次「素材已更新」。

### 2. 素材检查 / 导入向导

`program/src/api_wizard.py` + `ui/asset-wizard.js`：

菜单「环境设置 → 素材检查」打开，四步一把看清（每步都能跳过）：

| 步骤 | 数据来源 | 例子 |
|---|---|---|
| 立绘（表情 / 衣服） | `asset_report.missing` 里 `kind=portrait`，按衣服聚合 | `高中·冬装/微笑.png` |
| 场景背景 | `kind=cg` | `roof（roof.jpg）` |
| 语音 | 参考音频数量 + 0 字节文件 | `还没导入参考音频` |
| 提示词 / 世界书 / 记忆书 | `char_res.status()` | `未导入：记忆书` |

向导**不替你导入**（导入面板本来就有），它负责说清「缺什么、从哪进」；
底部有「重新扫描」（`?refresh=1` 现扫一遍）。

## 验证

- 真机：往 `res/assets/cg` 放一个文件 → 6 秒后 `gen` 0→1、`last_kinds=["assets"]`、`errors=[]`；
  删掉 → 2；同一份日志里 5 次 `/api/hotreload` 请求**一行都没记**（慢请求才记）。
- 真机探针：菜单打开向导后 DOM 里有 6 个区块、3 个按钮、20 段文字；
  `data-uitxt` 里能读到「素材检查 / 立绘（表情 / 衣服）/ 场景背景 / 语音 / 跳过」，
  统计行显示「检查了 468 个文件（117 MB）· 缺 0 项」；`WA2.hotReload.polling() === true`，无 JS 报错。
- `check_split` 从 91 降到 89（没新增告警）；`arch_map --check`、`param_table --check` 通过。

## 踩到的一处（探针的坑，值得记住）

第一版探针读 `box.textContent`，结果「盒子在、按钮在、字是空的」。原因是这个项目的
**字模渲染器**会把正文换成 `<img src="/api/text?text=…">`，原始文字留在 `data-uitxt` 属性里。
已经写进 `交接速览` 的坑和 `架构/05` 的验证一节：**探针读 `data-uitxt`，别读 `textContent`**。

## 没做 / 边界

- 轮询最坏延迟约 7 秒（2 秒扫描 + 0.8 秒稳定 + 4 秒前端轮询）；不是 inotify 那种即时。
- 只重画当前正在显示的立绘 / 背景；其它界面元素等下次刷新。
- 向导不做导入动作（就是这次不把文件搬运也做成向导步骤）。
